# Scale

## Quick answer
- Size contrast creates drama and hierarchy: the bigger element dominates. `[Practice]`
- A known-size reference (a person, a car) tells viewers how big everything is. `[E-strong as a depth and size cue]`
- Ratio between the largest and second-largest element sets how decisive the hierarchy feels. `[Practice]`

## Definition
- **Scale**: size relative to other elements, the frame, or the viewer's body.
- **Proportion**: ratio of parts to each other and the whole.
- **Scale reference**: an object of known size used to read others.

## Mechanism
- Relative size is a depth cue (see `depth-space`). `[E-strong]`
- Larger elements attract more attention and carry more visual weight. `[Practice]`
- Bang: larger objects feel stronger. `[Practice] [Unverified]`

## Techniques
- `[Practice]` Tiny figure in a vast landscape: awe, isolation.
- `[Practice]` Extreme close-up of a small object: importance, intimacy.
- `[Practice]` Low angle plus wide lens: monumentality (see `camera-lens-movement`).
- `[Practice]` Forced perspective: near small object aligned with far large one.
- `[Practice]` Type scale: big headline vs small body sets hierarchy (see `typography`).
- `[Practice]` Big-medium-small variety in element sizes.

## By medium
- Photography: include a human for scale in landscapes and architecture.
- Design: a single oversized element (number, word, image crop) for impact.
- Film: shot size changes scale of emotion (see `shot-grammar`).
- Broadcast: stat graphics often use one oversized number with small labels.

## How to measure
- Element areas from segmentation or layout boxes → ratio of largest to second largest.
- Subject area as % of frame.
- Face height as % of frame height (shot size proxy).

## Failure modes
- All elements similar size: no hierarchy.
- No scale reference when size matters to the story.
- Accidental scale confusion (a far object reads as a small near one).

## Critique questions
- What is biggest, and should it be?
- Can the viewer tell how big things are?

## Terms
- scale, proportion, relative size, scale reference, monumentality, forced perspective, size contrast
