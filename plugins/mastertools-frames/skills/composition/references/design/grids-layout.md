# Grids and layout

## Quick answer
- Grids systematize proximity and alignment so scale, weight and space can carry the hierarchy. `[Practice; Gestalt evidence E-strong]`
- Pick the grid from the content: one column for reading, multiple columns or modules for mixed content. `[Practice]`
- Break the grid deliberately for the focal element, never by accident. `[Practice]`

## Grid types `[Practice]`
- Manuscript (single column): long text, books, simple slides.
- Column grid (2 to 12 columns): editorial, web, broadcast full-screens.
- Modular grid: columns plus rows creating modules; complex information.
- Hierarchical grid: irregular, built from content needs (web homepages).
- Baseline grid: shared horizontal rhythm for type.

## Parts
- Margins, columns, gutters, rows, modules, fields (grouped modules), flowlines (horizontal alignments), baseline.

## Why grids work
- Alignment creates implied lines and reduces orientation variability (lower clutter). `[E-strong via clutter research]`
- Consistent spacing makes proximity grouping reliable (see `gestalt`). `[E-strong]`
- Repetition across pages or assets raises fluency and unity (see `fluency-complexity`).

## Masters and texts `[Unverified]`
- Müller-Brockmann, *Grid Systems in Graphic Design* (1981): grid as objective order.
- Gerstner, *Designing Programmes* (1964): grids as programs that generate many layouts.
- Tschichold, *Die neue Typographie* (1928): asymmetric modern layout.
- Vignelli, *The Vignelli Canon* (2010): discipline, few typefaces, grids.

## Techniques `[Practice]`
- Spacing scale (e.g. 4 or 8 px base) for all gaps.
- Larger gaps between groups than within groups.
- Align edges, not centers, for strong flowlines in text-heavy layouts.
- One element breaking the grid (bleed, overlap, rotation) becomes the focal point.

## By medium
- Broadcast full-screens: 12-column grid inside graphics safe; consistent across the package.
- Social: grid adapted per ratio (see `reframing`).
- Posters and key art: hierarchical or freeform grids with a strong focal element.

## How to measure (layout metrics from research)
- Alignment: average minimum x or y distance between element edges or centers. Lower is better.
- Overlap: average IoU between element boxes. Usually near zero unless intended.
- Occlusion: share of salient image area covered by text or graphics.
- Spacing consistency: variance of gaps within groups vs between groups.
- Caveat: the Layout-Corrector authors note these metrics do not necessarily correlate with perceived quality. Use as linting, not judgment.

## Failure modes
- Near-miss alignment (elements almost aligned).
- Equal spacing everywhere, so no groups.
- Accidental grid breaks.

## Critique questions
- What grid is in use, and is it consistent?
- Which element breaks it, and is that the focal point?
