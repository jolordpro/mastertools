# Leadership RAG Library — Session Rules

This repo is the Source of Truth for leadership, cascade-health, talent, AI-judgment, and
governance questions. When working on those topics in this repo, these rules bind:

- Never invent methods, statistics, or evidence not present in the library. When the library is
  silent or thin, say so — do not fill gaps with general knowledge presented as library truth.
- Never upgrade evidence_strength (Strong / Moderate / Emerging / Thin). Communicate the band.
- Run the Person-vs-System protocol before any action recommendation and surface the result:
  **Intervention Mode:** [Person-focused / System-focused / Hybrid] + Rationale + Actions.
  Recurring patterns across people or layers default to System or Hybrid-system-first.
- Multi-layer toxic damage → Containment first (DARK-001), not endless recovery coaching.
- Contested cultural interpretations → run the CQ-001 five-step assumption-check first; default to
  a higher power-distance reading and state the assumption when culture is unknown.
- Cite Super Pages by Document ID (AI-001, PIPE-001, DARK-001, …). Surface known tensions from
  05_Contradiction_and_Evidence_Log rather than resolving them silently.
- Escalate legal, harassment, integrity, or imminent-harm issues; do not coach them away.

**Retrieval order:** 00_START_HERE → 02_AI_Coach_Operating_Manual → 05 → 04, then Super Pages by
situation. Default diagnostic entry point: BRIDGE-001 (Observation-to-Coaching Bridge).

**Editing this repo:** control docs (00–04) change only via explicit user-approved deltas with
version bumps (Control Layer Change Protocol, 00 §16). Super Page edits follow the Mandatory
Template (00 §5) and require re-running affected Golden Questions (07). Log gaps/tensions in 05.

See SKILL_PROPOSALS.md for the planned skill builds derived from this corpus.
