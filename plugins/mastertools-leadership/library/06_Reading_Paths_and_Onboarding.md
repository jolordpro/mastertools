## 1. How to Use This Library (Quick Start)

1. **Always begin with intent.** What is the primary question or situation? (Cascade diagnosis, Passage 2 transition, AI judgment risk, toxic high performer, sponsorship system, board governance, cultural calibration, etc.)
2. **Retrieve by domain, not by keyword alone.** Use the Master Index and the paths below. Prefer Super Pages whose `use_case` and `leadership_level` match the situation.
3. **Respect evidence_strength.** Emerging claims must be communicated as Emerging. See CTRL-05.
4. **Run Person-vs-System.** Default bias is recorded on each Super Page. Capacity problems are usually system/role first; capability problems are person-focused only when capacity exists.
5. **Hold universal cascade-health requirements** (safety sufficient for learning, energy surplus, non-toxic high performance, Enabling Leadership, long-term judgment capacity, generativity) while calibrating expression via CQ-001.
6. **When in doubt, start with BRIDGE-001 + the relevant substrate (SAFE / ENERGY / CAP) + the domain Super Page.**

## 2. Core Reading Paths (Recommended Sequences)

### Path A — New AI Coach / System Implementer Onboarding
**Goal:** Understand governance, retrieval rules, and the operating system before domain deep-dives.  
1. 00_START_HERE

5. 05_Contradiction_and_Evidence_Log  
6. BRIDGE-001 (Observation-to-Coaching Bridge & Dashboard)  
7. SYS-CAS-001 (meta-operating system)  
Then proceed to substrates and domain pages as needed.

### Path B — Cascade Diagnosis (Leader of Leaders facing multi-layer problems)
**Goal:** Diagnose and intervene on cascade health.  
1. BRIDGE-001  
2. SAFE-001  
3. ENERGY-001  
4. CAP-001  
5. SYS-CAS-001  
6. Relevant domain page (DARK, AI, SPONSOR, PIPE, PEOPLE, etc.)  
7. CQ-001 (if cross-cultural or contested interpretation)

### Path C — Passage 2 / Leading Leaders Transition
**Goal:** Support or diagnose incomplete Managing Others → Managing Managers transitions.  
1. PIPE-001  
2. CAP-001  
3. PEOPLE-001  
4. ENERGY-001  
5. SPONSOR-001  
6. BRIDGE-001  
7. SAFE-001

### Path D — AI Transformation & Judgment Health
**Goal:** Design or diagnose AI-era judgment, oversight, and Agent Manager capability.  
1. AI-001  
2. SAFE-001 (AI voice)  
3. ENERGY-001 (cognitive load / always-on)

1. BOARD-001

3. ENERGY-001

**Goal:** Avoid ethnocentrism and relativism; calibrate diagnosis and intervention.

## 5. Onboarding Checklist for New Users / Implementers

- [ ] Read 00_START_HERE (anti-hallucination rules, retrieval hierarchy, Person-vs-System protocol)
- [ ] Skim 01_Taxonomy (controlled vocabulary)
- [ ] Read 02_AI_Coach_Operating_Manual (if implementing or prompting an AI Coach)
- [ ] Note evidence_strength rules in 05_Contradiction_and_Evidence_Log
- [ ] Choose a Reading Path that matches current primary use case
- [ ] Bookmark BRIDGE-001 as the action-conversion engine
- [ ] Treat CQ-001 as cross-cutting: run cultural assumption checks on contested diagnoses
- [ ] When capacity vs. capability is unclear, start with PEOPLE-001 + ENERGY-001 before heavy skill development
- [ ] When toxic or results-shield patterns appear, go to DARK-001 early (do not default to endless coaching)
- [ ] When AI judgment or oversight is involved, hold AI-001 + SAFE-001 + ENERGY-001 + BOARD-001 together
