## 3. Expanded Reading Paths (Decision-Oriented)

> **Path lettering precedence (added 2026-07-26).** Three documents define reading paths with

> and `06_Reading_Paths_and_Onboarding.md`. **When a Super Page §8 note or `04_Retrieval_Playbook`
> cites a path letter, it means the lettering in THIS document (CTRL-03 §3)** — it is the only one
> defining Path K (Overwhelmed / High Cognitive Load), which `04` §5 and several Super Page §8
> sections depend on. Treat `06`'s paths as onboarding curricula with independent numbering, and
> `00` §14 as an abbreviated summary. *Flagged for consolidation in a future hardening pass; the

### Path A — AI Coach / New Session Bootstrap
**Entry trigger:** New conversation or Coach needs orientation.  
**Sequence:** 00 → 02 → this Index → Primary Super Page.  
**Success criteria:** Correct Super Page(s) loaded and Person-vs-System pre-scan complete.  
**Protocols in force:** Full Pre-Response Reasoning Protocol (02).

### Path B — Cascade Health Diagnosis (Primary Diagnostic Path)
**Entry trigger:** User describes multi-layer problems, silence, recurring patterns, energy issues, judgment concerns, or “something feels off” in the cascade.  
**Sequence:**
1. BRIDGE-001 (Dashboard + Bridge)
2. Branch on red/yellow indicators:
   - Safety → SAFE-001
   - Energy → ENERGY-001
   - Capacity / mental models → CAP-001
   - Judgment / AI → AI-001
   - Multi-layer distortion / skip-level → BRIDGE-001 multi-layer sections + SAFE-001 + DARK-001 if toxic signals
   - Generativity / pipeline health → GEN-001 + PIPE-001 + SPONSOR-001
3. **Always return to BRIDGE-001** for Person-vs-System decision + dosage calibration + action design.
**Mid-conversation re-route:** Any new high-severity signal (toxic actor, energy collapse, Artificial Harmony, Decision Drift) → name the shift and pull the new Super Page immediately.  
**Success criteria:** Clear Intervention Mode declared, dosage set, cascade implications named.  
**Golden Question anchors:** 1, 3, 4, 9, 13, 14, 15.

### Path C — Talent System Design / Audit
**Entry trigger:** User wants to design, redesign, or audit high-potential, sponsorship, succession, or people-leader systems.  
**Sequence:** SPONSOR-001 → GEN-001 → PIPE-001 → PEOPLE-001 → CAP-001 → SAFE-001 → ENERGY-001 (substrates) → BRIDGE-001 (how Leaders of Leaders will coach/sponsor inside the system).  
*(High-potential identification is not a separate page in this package — PIPE-001 §2.4 carries the Passage 2 selection evidence set, and SPONSOR-001 §2.4 carries portfolio and gap analysis. See CTRL-08 §2 for the Tier 2 candidate.)*  
**Protocols:** Person-vs-System on every major design choice; dosage for implementation.  
**Success criteria:** System design explicitly protects safety, energy, and capacity for complexity.  
**Golden Question anchors:** 5, 7, 10.

### Path D — AI Transformation & Judgment Stewardship
**Entry trigger:** AI adoption, agent management, decision rights, override quality, judgment drift, or oversight concerns.  
**Sequence:** AI-001 → SAFE-001 (voice about errors) → ENERGY-001 → CAP-001 → BRIDGE-001 → BOARD-001 (if governance-level).  
**Protocols:** Elevate evidence_strength communication (many claims Emerging); Person-vs-System on skill vs. decision-rights design.  
**Success criteria:** Judgment Loops and Decision Drift explicitly assessed; safety for override confirmed.  
**Golden Question anchors:** 8, 12.

### Path E — Middle Manager / Passage 2 Development at Scale
**Entry trigger:** Need to develop managers of managers or fix Passage 2 failure modes.  
**Sequence:** PIPE-001 (Passage 2) → CAP-001 + Enabling Leadership → BRIDGE-001 → ENERGY-001 → SAFE-001 → PEOPLE-001.  
**Focus:** Scalable curricula + observation-to-coaching skill transfer + second-order observation development.  
**Protocols:** Heavy use of Second-Order Observation moves (02 §5) and dosage calibration.  
**Success criteria:** Managers can run Person-vs-System and protect cascade health with their own teams.  
**Golden Question anchors:** 7, 13.

### Path F — Crisis / Toxic Cascade
**Entry trigger:** Active toxic high performer, Jekyll-and-Hyde leadership, severe safety collapse, or cascade contagion.  
**Sequence:** DARK-001 (first) → SAFE-001 → ENERGY-001 → BRIDGE-001 (Containment vs. Recovery decision + Person-vs-System).  
**Protocols:** Escalate immediately on legal/harassment triggers. Prefer containment when recovery is unrealistic.  
**Success criteria:** Immediate risk contained; clear mode (containment vs. recovery) declared; surrounding cascade protected.  
**Golden Question anchors:** 2, 11.

### Path G — Board Fluency & Multi-Stakeholder Governance
**Entry trigger:** Board preparation, governance design, or board-level cascade effects.  
**Sequence:** BOARD-001 → AI-001 → Multi-Layer Sensing → SAFE-001 → GEN-001.  
**Protocols:** System-focused bias; Person-vs-System on board decision rights.  
**Success criteria:** Board behaviors that protect (or threaten) organizational judgment culture are explicit.

### Path H — Generativity & Wisdom Transfer System Design
**Entry trigger:** Design reverse mentoring, legacy, succession beyond replacement, or multi-directional wisdom flows.  
**Sequence:** GEN-001 → SPONSOR-001 → ENERGY-001 (surplus required) → SAFE-001 → CAP-001 → BRIDGE-001.  
**Critical check:** Generativity collapses without energy surplus and safety.  
**Success criteria:** System design includes energy and safety as non-negotiable inputs.  
**Golden Question anchors:** 10.

### Path I — Cross-Cultural Cascade Design
**Entry trigger:** Multi-cultural teams, global leadership, or cultural contingencies of voice/challenge/sponsorship.  
**Sequence:** CQ-001 → SAFE-001 (cultural contingencies) → SPONSOR-001 + GEN-001 → BRIDGE-001 → ENERGY-001.  
**Protocols:** Apply Cultural Context Protocol (02); never assume low power-distance norms.  
**Success criteria:** Voice, challenge, and sponsorship practices are culturally calibrated.

### Path J — Second-Order Observation & Meta-Capacity Development
**Entry trigger:** Leader of Leaders wants to improve their own observing, judgment under complexity, or coaching skill.  
**Sequence:** BRIDGE-001 (second-order sections) → CAP-001 → SYS-CAS-001 → ENERGY-001 → SAFE-001.  
**Protocols:** Heavy use of the 6 Second-Order Observation Coaching Moves (02 §5).  
**Success criteria:** User demonstrates improved ability to observe their own filters, energy effects, and system-generated patterns.

### Path K — Overwhelmed / High Cognitive Load Entry
**Entry trigger:** User is depleted, flooded, or says “I don’t know where to start.”  
**Sequence (deliberately short):**  
1. ENERGY-001 (immediate recovery / oscillation check)  
2. BRIDGE-001 (one high-leverage observation + one Person-vs-System question only)  
3. Stop. Calibrate dosage to near-zero additional load.  
**Success criteria:** User has one clear next micro-step and protected recovery capacity. Do not open multiple Super Pages.

## 4. Multi-Hop Relationship Quick Reference (Highest Frequency)

- Psychological Safety **enables** Enabling Leadership & Judgment Loops / AI Override Quality  
- Energy Management **enables** Capacity for Complexity **and** Generativity  
- Capacity for Complexity **enables** higher-quality Person-vs-System decisions  
- Energy ↔ Psychological Safety (bidirectional; vicious or virtuous cycles)  
- Toxic High Performer (uncontained) **threatens** surrounding Energy + Safety + Capacity + Cascade Health  
- Decision Drift **threatens** Human Evaluative Capacity **and** Capacity for Complexity over time  
- Artificial Harmony **threatens** Multi-Layer Sensing Quality  
- Board Decision Rights / Behavior **cascades into** Organizational Judgment Culture  
- Observation-to-Coaching Bridge **integrates with** Cascade Health Dashboard  
- Generativity **requires** Energy surplus + Safety + Sponsorship  
- Skip-Level Sensing Quality **cascades into** Team Psychological Safety & Truth-to-Power  
- Challenge behaviors **are moderated by** prior Supportive + Consultative climate

## 6. How the AI Coach Must Use This Index

1. At session start or when lost → consult this Index for highest-leverage Super Page and Path.
2. Classify the user’s need into Diagnosis / Design / Crisis / Development / AI-Governance / Meta (Section 2).
3. Select the matching Path and follow its sequence, entry triggers, and success criteria.
4. **Every Path that reaches action design must run Person-vs-System + Dosage Calibration** (02).
5. When a Dashboard indicator turns red/yellow or new high-severity information appears → re-route explicitly and name the shift.
6. Prefer the Super Page that owns the primary construct, then pull integrating pages via multi-hop relationships.
7. For overwhelmed users → default to Path K.
8. Use Golden Questions as live probes mapped in Section 5.

## 7. Construction Priority Rationale (Strengthened)

We build in the listed order because:
1. **SYS-CAS-001 + BRIDGE-001** form the meta-operating system (systems thinking + observation-to-action conversion) required by every other page.
2. **SAFE-001, CAP-001, ENERGY-001** are the three load-bearing substrates without which cascade health is impossible.
3. **AI-001 and DARK-001** are high-stakes, high-frequency failure domains with severe cascade contagion risk.
4. **SPONSOR-001 + GEN-001 + PIPE-001 + PEOPLE-001** constitute the core talent cascading system.
5. Remaining pages complete coverage with slightly lower immediate coach-conversion urgency or higher dependence on the foundation pages.

This order maximizes early coach utility and cascade protection.
