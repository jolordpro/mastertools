# Decisions · <project>

One entry per decision, in the D-log form, so later builds can grep it
(the decisions ledger, when the ledgers module is installed, can index it). Source is one of: User said · Claude inferred (user delegated) ·
Claude decided (user delegated) · Claude decided (solo, S-<n>) · Claude proposed,
user picked.
