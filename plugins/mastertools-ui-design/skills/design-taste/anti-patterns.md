# Anti-patterns

Never ship these, at any dial position.

## Function
- A greyed-out main button with no reason. Say what is missing (canon 4).
- An empty or error state with no cause and no fix (canon 3).
- A filter panel whose apply button gives no count (canon 2).
- Pop-ups on page load that block the task (promo, sign-in). Seen on Airbnb and Booking; not copied.
- Touch layouts with targets under 44 pt (iOS) or 48 dp (Android). Text under WCAG AA contrast.
- Separate "Sign in" and "Sign up" doors when one identifier-first door works (canon 8).

## AI tells (from frontend-design; they apply here)
- Cream background (near #F4F1EA) with a serif display and a terracotta accent.
- Near-black page with a single acid-green or vermilion accent, used by default.
- The SaaS card kit: identical rounded cards, one radius, the same soft grey shadow, gradient washes.
- Template chrome: tracked ALL-CAPS eyebrows above every heading, "A · B · C" meta strings, "→" on every link, numbered 01/02/03 markers on things that aren't a sequence.
- Scattered fade-and-slide-up entrances on every section.

These are tells only when used by default. A pattern proven by the canon (near-black text, pill buttons, chips) is not a tell.

## Scope
- Anything from a personal or client brand (colours, type, voice).
- Lifted layouts, code, logos, brand colours or illustrations from any product.
- A principle seen in only one year's award work.
