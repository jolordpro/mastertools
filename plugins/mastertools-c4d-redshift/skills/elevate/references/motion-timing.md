# Motion and timing (MOT)

Every motion note says "verify in playback". Judge from the ease readout and frame strips, never from a single still.
Taught in: SOM Animation Bootcamp (Joey Korenman) · SOM Advanced Motion Methods (Sander van Dijk) · SCAD MOME 711, 715, 315.

## Read
- **X:** Spacing and easing quality can't be judged from stills.
- **R:** Key times; ease speed and influence; count of default eases; layer offsets; durations; fps; C4D F-curve tangents.
