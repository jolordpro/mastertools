# Gold examples

This folder ships with the template only. Gold examples are optional: user-approved critiques of real scenes from the user's own work, kept in the user's overlay (`~/.claude/overlays/elevate/examples/gold/`) when present, or here. They are /elevate's strongest calibration lever (see `references/gold-examples.md`).

- **Target:** 6 for v1 (2 PB-LOGO, 2 PB-GLASS, 2 AE type piece), then 8–12.
- **Naming:** `<shot-type>-<nn>.md`, for example `logo-01.md`. Keep the marked frames beside it, named in the file.
- **Status:** an AI-drafted critique is not gold until the user edits and approves it.
- **Template:** `_template.md`.
