Figma Brand Studio (2021): four pillars (curious, vibrant, honest, bold) were set with leadership. New work is asked whether it still feels each one. Sub-brands (the design-systems conference) keep some brand elements and change the rest for wayfinding.

**Use it:** Turn principles into a question list reviewers can ask of any piece.
