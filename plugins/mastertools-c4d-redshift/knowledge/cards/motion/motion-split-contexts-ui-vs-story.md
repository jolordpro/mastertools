Val Head: the same rules should not cover UI motion and brand or illustration animation. Intuit splits storytelling and UI; Carbon splits productive and expressive easing; Material splits emphasized and standard. Adobe's first Spectrum pass covered UI only and drew questions about animated illustration.

**Use it:** State the contexts a system covers and say plainly which are out of scope for v1.
