A 2021 article by a self-described designer-engineer breaks an animation into element, trigger, duration, property, easing. Tokens hold duration (fast, base, slow) and easing (base, in, out); the designer specs trigger, which elements move and when each starts. Author level unverified, example values small.

**Use it:** Use as a simple template for what a token set covers and what the choreography spec adds.
