MotionXP [08:18-12:15]. Frame-by-frame exercise: a ball moving along a drawn path, noting where it slows and speeds. Copy the path keyframe and paste into position: each path point becomes a roving key that AE spaces automatically; dragging the end key changes overall speed; the speed graph is used since dimensions can't be separated. A higher key in the speed graph means faster through that point, lower means nearly stopping; strong ease either side of a raised key gives hang time; check the "continuous" box if handles separate. Alternative: precompose the layer, enable time remapping, add keys wherever a slowdown is wanted, ease them, and lift them, which also allows the value graph.

**Use it:** Technique for camera or object moves along a drawn path when each beat needs its own pacing.
