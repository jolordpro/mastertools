He built compass and HUD parts as shape layers with repeaters because they are procedural: a director asking for thicker lines is one click [15:11-16:13].
To make UI react to the flight footage, he parented a control layer to the footage-tracking motion and pick-whipped the master UI comp to it, so rotating one moves everything [16:45-18:51].
A little wiggle (heard as about wiggle(10,5), unsure) on UI elements adds believable motion [18:51-19:25]. Explosions used Particular, overexposed for flashes [19:25-19:59].

**Use it:** procedural shape UIs absorb director changes cheaply; add a parent controller for camera-matching motion.
