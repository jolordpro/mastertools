A view model is a set of named properties for a component or screen (e.g. a left-turn boolean). Engineers see which values the designer exposes; the designer binds them to animations, positions or sounds. Guido says Rive uses real engineering names (view model, data binding) so both roles share one vocabulary. If the engineer needs another field, they ask and the designer wires it up.

**Use it:** Name the inputs a motion component exposes, in the engineers' words.
