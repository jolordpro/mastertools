He used to link controls to Essential Graphics and animate from the comp above, but now duplicates the character template comp and animates inside the copy, because later tweaks to the base rig can break other shots [49:37-50:09].
Essential Properties paid off for repeated items: one bug rig with replaceable media for each logo, switchable side or top view, head rotation and adaptive resolution built an anthill quickly [50:09-51:10].
One bug leg was animated once with guide paths and reused with a frame offset on every leg [51:10-52:45]. He dislikes feedback that needs a rig rewrite; the cause is a rig without enough foresight [1:01:35-1:02:37].

**Use it:** decide when a shared rig is worth the risk: shared for many identical items, copied per shot when changes are likely.
