Guido Rosso (Dive Club, 2026-02-02) argues designers should work under the same constraints as the runtime, so what is seen in the editor is what ships. Reason given: a blur built another way never looks exactly the same once re-implemented. Rive built its own format, renderer and editor for this. Founders' claim, not independently tested.

**Use it:** Frame a motion spec as shared constraints, not a picture to be matched.
