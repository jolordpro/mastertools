Dickinson: early brands can begin with a few rules on how type moves, how the logo resolves, how an end frame locks up a CTA; add a system when much motion must be delivered. Keep the system living: refresh paid templates every quarter or half-year, build sub-systems for campaigns while keeping easing, timing and choreography.

**Use it:** Describe scope stages when positioning a system.
