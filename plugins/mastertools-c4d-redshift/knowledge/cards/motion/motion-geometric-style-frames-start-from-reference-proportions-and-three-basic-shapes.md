Kristina (Explainers Easy) [0:03-2:41]: define the main element from the script, then add two or three supporting elements, each with a reason you can state [0:03]; never illustrate without a reference photo because it gives shapes and proportions, and proportions make a vector read as a real object [1:07]; build from rectangles, triangles and circles, usually three to five shapes per object, adjusting anchor points (a TV tower is one sharp triangle) [1:37]; even one rectangle with openings reads as architecture [2:09]; repeat details across objects: small circles, thin lines, rounded corners everywhere [2:09]; in a sequence reuse an element (a street light) to tie scenes together [2:41]. The animation uses plain path animation and trim paths, no plugins.

**Use it:** Checks for a style frame: every object traceable to a reference, shape count kept low, and one repeated motif that ties frames together.
