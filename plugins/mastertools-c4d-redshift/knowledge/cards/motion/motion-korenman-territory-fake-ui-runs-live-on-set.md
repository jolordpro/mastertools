Usual method: shoot an empty screen, track it, composite the UI later, and roto fingers and add light; the DP also has to guess focus and exposure for a screen that shows nothing [30:12].
Territory (per the host, from a School of Motion interview) made the UI an interactive file on the real prop: typed keys produce the right text with the right timing, a chat bubble animates, and the actor's finger is genuinely lit [30:22-30:52].
Reported result: directors, DPs and actors prefer it; changes on set no longer need a developer to recompile [31:23].

**Use it:** shows the production-versus-post trade: moving screen content to the shoot saves roto and tracking, and the motion designer still builds it.
