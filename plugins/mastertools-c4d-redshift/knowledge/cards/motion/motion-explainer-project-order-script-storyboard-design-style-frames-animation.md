Marvinta (studio owner, Philippines) lists the order [1:13-3:48]: script (copywriting) for explainers and some commercials; storyboard as rough drawings for client or internal visualisation; design is the actual look; style frames take that design and apply it to the rest of the storyboard frames; then animation (character, motion graphics, VFX; cut-out rig vs frame by frame). In some studios design and style frames are done by different designers. Skills he lists: storyboarders need contrast, perspective (even for flat styles, to know which rules to break), compositions and coherent sequences [4:51-5:24]; designers add colour harmony, typography and designing for motion, not still [6:26-6:58].

**Use it:** The coach can use this as the stage order for a new project and ask which stage the client is signing off.
