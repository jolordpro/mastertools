Salih compares it to a camera, a video file and a player. The player supports well under a twentieth of After Effects, by design, to keep the library small. Same JSON can be restyled at runtime (colour changes, dark mode logo) and tied to gesture or scroll progress. Tools like this let a designer ship the real asset, not concept art.

**Use it:** Describe a motion handoff as three parts: authoring, data, player, and state the supported subset.
