Jake in Motion [13:42-17:25]. Value graph (value over time) suits a ball bounce: identical ground keys, and the bounce comes from the curve shape, with X and Y separated. Speed graph (rate of change) works on every property with one curve, so a combined Position keeps a drawable motion path with Bezier handles: shape the route in the comp, shape the timing in the graph. Redoing the bounce in the speed graph is described as very hard, and a bounce rebuilt on a combined path looked unnatural [14:24].

**Use it:** Pick the graph by job: bounce, overshoot or settle goes to the value graph; travel along a drawn path goes to the speed graph. The coach can say this when a user fights the wrong graph.
