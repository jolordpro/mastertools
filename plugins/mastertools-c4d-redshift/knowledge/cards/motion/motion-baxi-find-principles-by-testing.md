Start from brand traits (F1: inertia and speed, then warmth and humanity). Run many tests, then curate what feels right.
Designers must write what is in their head as a sentence; naming it changes what the team sees (staccato technological vs capturing the pit-lane entry).
Choices tested include ease in/out versus fades, no numbers shared.

**Use it:** Add a step where each motion test gets a one-sentence description before it is kept.
