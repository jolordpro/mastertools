Jake in Motion [18:40-23:44]. Default Easy Ease looks plain. Press U to show all keys, select properties that move alike (window scale, people sliding in, plant slides), open the speed graph and pull one incoming handle out: all selected keys change together. For things appearing, ease little out of the first key and a lot into the rest position. Hold Shift while dragging a handle so it snaps horizontal, and keep the magnet on so it snaps to the 0 baseline [11:18]. Keys on different timings can end up too extreme, so back those off by hand. Overshoot and bounce keys are handled separately, preferably in the value graph [22:10]. Keep keys that are synced (scene scale plus text) selected together so they get identical easing [21:08].

**Use it:** Ease batches of like-moving keys together first, then fix outliers one at a time, and compare against plain Easy Ease to confirm the gain.
