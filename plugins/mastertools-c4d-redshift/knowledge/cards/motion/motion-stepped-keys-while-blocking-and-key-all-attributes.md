Alex Grigg's graph-editor rules for pose-to-pose [12:36-13:41]: stay in stepped keys while setting extremes and breakdowns so the software cannot build in-betweens for you; linear mode is acceptable for placing breakdowns, but go back to stepped while deciding timing. If a key should hold, copy it to the end of the hold so the hold survives the switch to spline. Key every attribute on every key pose, even unchanged ones, which makes the switch from stepped to spline simpler.
If a breakdown ends up in the wrong place, slide it only as a last resort during in-betweening [12:01-12:36]. Use spacing thinking: a bouncing ball's breakdown sits near the start or end pose, not the middle [12:01].

**Use it:** apply to C4D and AE blocking passes before easing; a stepped-key preview is the honest timing check.
