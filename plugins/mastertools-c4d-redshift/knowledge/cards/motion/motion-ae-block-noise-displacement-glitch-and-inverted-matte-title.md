SonduckFilm [07:02-10:50]. Hollow title: a rectangle shape layer under the title with Track Matte set to Alpha Inverted Matte, pre-comp both and scale the comp to 0 with an F9 ease on the last key. Glitch: a solid with Fractal Noise, noise type Block, brightness about -150 to -200, contrast about 200, Uniform Scaling off with scale width about 400 and a smaller height, evolution keyed; pre-comp it as a map; on an adjustment layer add Displacement Map using it, raise max horizontal and vertical displacement, and tick Wrap Pixels Around to avoid edge gaps. Trim the adjustment layer so distortion alternates with clean moments; the author concedes it may be overdone and says it works better at the start of each layer.

**Use it:** Treat it as a seasoning: short bursts timed to beats, not continuous distortion.
