Jake in Motion [06:10-06:41]: with Position combined, the value graph handles are locked and show nothing editable. Right-click Position, pick Separate Dimensions, shift-click both X and Y, and each gets its own editable curve. Recombining the dimensions throws the custom easing away [12:21]. The Path property has no value to chart, so its 'value graph' shows speed only [17:30].

**Use it:** When a rig keyframes Position and someone asks for a bounce or overshoot in the value graph, separate dimensions first, or ease in the speed graph instead. Warn that recombining loses the easing.
