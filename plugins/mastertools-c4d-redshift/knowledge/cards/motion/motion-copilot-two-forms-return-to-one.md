Every Copilot gesture uses the same two forms moving relative to each other and ending as a single shape. The icon starts from a plain square so the shape stays readable in every frame of motion.

**Use it:** A one-sentence behavior rule plus a base shape that survives mid-motion is enough to spec an identity in motion.
