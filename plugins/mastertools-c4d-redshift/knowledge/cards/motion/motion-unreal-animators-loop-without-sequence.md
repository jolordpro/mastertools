Speaker is David Grownick, Epic senior product specialist and ex Fox Sports real-time graphics, so vendor view. Set min and max rotation and the object animates until stopped, useful for lobby and install screens and pre-event loops [14:00-15:01]. An add-to-sequence button gives the same effect in a timeline, keyframing only the track [15:01-15:32].

**Use it:** Use for background motion where no one wants to keyframe.
