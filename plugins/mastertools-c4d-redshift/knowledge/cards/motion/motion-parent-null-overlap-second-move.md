MahdiEdits [01:32]: keyframing A to B to C directly leaves a pause at B. Instead animate A to B on the object, parent it to a null, and start B to C on the null around the middle of the first move.
The object then keeps moving at B. Repeat with more nulls for more overlaps [02:02].

**Use it:** recommend this fix when the dead-stop test finds zero overlap.
