Kramer's render folders are split into test, shot, output and final render. Project files are named _v1, _v100 and so on, with a leading underscore so they sort first, because folders can reach about 100 and names like final-super-final are a mess. The project tree runs project folder, category, project, 2D assets, 3D assets, reference files, previs, After Effects folder and main assets (nine items). In Element 3D, Save 3D keeps all settings in one file with its links so work can be restored. [§1]

**Use it:** Name render stages by intent so a draft is never mistaken for a final.
