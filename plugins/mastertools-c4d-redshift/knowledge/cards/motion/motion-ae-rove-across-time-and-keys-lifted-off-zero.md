Jake in Motion [15:26-16:59]. Right-click a middle keyframe and choose Rove Across Time: it ignores its own time and slides along the curve as neighbouring keys or the graph change. Only the start, middle and end keys are fixed in time. If the speed keys sit on the 0 pixel per second baseline the object comes to rest at each one; lift them off the baseline when the object must keep moving but still ease.

**Use it:** Use for a camera or object that must pass through poses without ever stopping: rove the in-between keys and raise the speed keys off zero.
