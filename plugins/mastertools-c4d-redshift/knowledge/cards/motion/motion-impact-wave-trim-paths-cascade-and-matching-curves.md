Korenman [26:49-35:01]: stroked rectangle (2 px), size grows over one second, Trim Paths end 50% with offset rotating 90 degrees and a start animated to match the end so the shape erases. All keys F9 then invert to a fast-out, slow-end 'pop'; offset curve matched to the size curve by viewing both [29:33-30:37].
Cascade: duplicate, scale 150% / 10% less per copy, offset 2 frames (Option + Page Down), rotate 90-degree steps. On each landing, Cmd D + [ places a new wave; rotate pre-comps 90/180/270 so overlaps differ. Self-critique: 2 frames too tight, 3-4 and a bit random better [34:30].
Shortcuts: U shows keyed properties, UU shows changed ones; minus and plus zoom time.
