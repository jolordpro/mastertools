Announced between Octane 3 and 4: a subscription "in between" a standalone licence and a server node. The first demo was a 3ds Max plugin with no GPU in the machine whose live viewport ran as fast as with one attached; target users included Mac Pro owners with no good GPU option [17:35-18:19].
Planned later: one shared Octane Engine node that Nuke, After Effects, Maya and Unreal Engine all plug into, asynchronous rendering, baking a scene and feeding it back as a texture, and a light-field cache for biased techniques [18:48-19:34].
Roadmap claims, not shipped results; treat as the speaker's plans.

**Use it:** the idea of one remote render service feeding several DCC apps is the shape later cloud tools followed; use as background only.
