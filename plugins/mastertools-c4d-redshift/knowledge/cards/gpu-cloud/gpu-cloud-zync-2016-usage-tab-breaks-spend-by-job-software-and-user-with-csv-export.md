The usage view shows total spend by job, software and user, answering how much a spot for a client cost and what each artist used, and exports CSV to feed Shotgun or billing; producers liked it [31:10-32:11]. Admin and user roles differ: users control the web console, admins see usage and config and add users [32:11]. For big sequences on a limited line (he mentions VR) the transfers page lets you prioritise which files come down first and cap simultaneous downloads [30:09]. The queue is web-based, so the job can be watched from a phone [11:26].

**Use it:** copy these features: per-job cost lines a producer can read, a CSV export, and a download throttle.
