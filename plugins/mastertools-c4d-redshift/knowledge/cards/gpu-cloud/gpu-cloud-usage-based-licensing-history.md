Thinkbox/AWS (8 Jan 2020) for C4D render nodes; Conductor (12 Aug 2020) for C4D and Redshift per minute. AWS Deadline Cloud (27 Jan 2025) sells usage-based licences for C4D and Redshift on service-managed fleets; Redshift carries an extra licence charge.
Deadline Cloud also lets you bring your own licence server and mix both (yours first, then metered).
Merged from `pipeline-maxon-ubl-history`: AWS Thinkbox Marketplace got C4D command-line UBL on 8 Jan 2020. Conductor got C4D plus Redshift UBL on 12 Aug 2020, billed per minute. Current rates were not found.

**Use it:** a metered Maxon licence route exists without a private Maxon deal; the rate tables were not retrievable, so get quotes.
Transcript support: AWS speaker (2014): cloud scale was capped by the number of render licences a small studio owned; large houses had effectively unlimited licences; a cloud licensing model was still missing (https://www.youtube.com/watch?v=cm4sPe1nLjU [15:41])
Transcript support: AWS Thinkbox described per-minute usage-based licensing for 500 to 3,000 node bursts and bring-your-own licences in 2019; the 2016 panel https://www.youtube.com/watch?v=hIxnygxsdmc [09:29-11:31] shows vendors asked to meter and keep price near on-prem (https://www.youtube.com/watch?v=Fl_FdVgp2E0 [14:32-15:34])
Transcript support: presenter (July 2024) says Deadline Cloud bills compute plus a render licence per use, with no prepaid buckets as in older Deadline. (https://www.youtube.com/watch?v=kyaphnaCDEU [08:25])
Transcript support: Prives (Apr 2017) says Amazon had just bought Thinkbox, the Deadline maker, a few years before the Jan 2020 usage-based C4D licensing. (https://www.youtube.com/watch?v=F1KVCGox1TA [16:10])
