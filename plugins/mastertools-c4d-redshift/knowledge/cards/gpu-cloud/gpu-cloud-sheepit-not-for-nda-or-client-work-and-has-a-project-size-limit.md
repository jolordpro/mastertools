Whole project files (models, textures) are sent to volunteers' computers, and files are only supposed to be deleted afterward, with no absolute guarantee [08:54][09:27]. Data is encrypted in transit but can be read on the volunteer's machine by a determined person; rendered thumbnails show on the website [09:27][09:57]. Client contracts often forbid such services, and SheepIt's own FAQ calls the community farm better for personal or open projects [09:57][10:29]. A project size limit blocks scenes with gigabytes of textures; commercial farms accept dozens of GB for a price, so you must compress textures or link assets [10:29][10:59].

**Use it:** a shakedown/estimator rule: never send unaired sports graphics or client assets to a public farm; check the NDA first.
