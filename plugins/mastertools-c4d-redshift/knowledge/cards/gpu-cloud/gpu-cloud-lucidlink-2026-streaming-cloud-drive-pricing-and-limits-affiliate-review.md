The reviewer (Consumer Edge, affiliate links in the description, so treat as promotional) says files stream from the cloud and open as if local, with no sync step; setup under two minutes by naming a file space and picking a data location [00:31-02:05].
Plans as read aloud: Starter 100 GB per user at 7 dollars a month; Business 400 GB per user at 32 dollars a month, 27 if paid yearly; Enterprise on quote; 30-day free trial with no card; extra storage billed at a flat rate [02:37-03:40].
Downsides he names: setup is not beginner-friendly (system paths, cache settings), and no internet means no access, so key files are pinned offline [04:11-04:42].
He found Backblaze B2 fine for cold storage but not for a live production pipeline [04:42-05:44].

**Use it:** a candidate for sharing big project folders with a remote client or editor; check current prices and test with a Redshift texture folder before relying on it.
