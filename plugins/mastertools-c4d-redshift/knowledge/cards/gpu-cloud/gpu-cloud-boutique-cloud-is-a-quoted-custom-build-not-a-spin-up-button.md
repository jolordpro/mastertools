Kelsey says Center Grid is deliberately not a click-to-spin-up-15-machines site: the team asks what the studio is working on, proposes a spec (CPU, VRAM, storage, render capacity), then supports tweaks afterwards [30:26-31:27]. Published options are grouped as buckets (a workstation with set core count, VRAM and a GPU share) and nearly always customised [15:01-16:02]. Render-only capacity is available without a desktop, with GPUs or CPU only [33:00-34:02]. Example of the usage pattern: 25 machines for a six-month project, then returned; larger clients may agree a minimum commit they never dip below and scale up on top, month to month [32:00-33:01]. Customers he names: Boxel Studios (name as captioned; Superman and Lois, Avengers films work, virtual workstations), small startups founded by ex-big-studio supervisors, and freelancers [34:16-36:36]. A dinosaur documentary-style episodic series was built on the vendor's virtual workstations [09:19-09:51]. Growth described as steady but slow [36:05].

**Use it:** for a small studio, expect a sales conversation and a custom spec rather than self-serve pricing; use the 25-machines-for-six-months pattern as a sizing example for a monthly-rental bid line.
