A Google product manager's timeline, so promotional [00:07-17:45]. 2012: Zync built for Zero VFX (Boston), then Atomic Fiction; 2013: Flight, said to be the first Hollywood film done fully on cloud [05:19]. 2014: Google bought Zync, Microsoft bought Green Button (renamed Microsoft Batch) [06:51]. Framestore used GCP to burst past on-prem peaks [08:25-09:27]. 2015: Thinkbox Deadline shipped Cloud Wizards; Deadline used by roughly 50 to 60% of major studios [11:01]. Aug 2016: Autodesk partnership to run Maya on GCP [14:06]. 2016: MPC's Jungle Book (Oscar for VFX) ran a hybrid pipeline, on-prem plus GCP burst [15:39]. 2017: Amazon had recently bought Thinkbox [16:10].
Sizes: Flight about 7 million core hours; Atomic Fiction's The Walk (2015) 9.1 million on GCP; Jungle Book up to 14,000 cores [17:15-17:45]. The rest of the Jungle Book figures are garbled in the captions (nodes, wall-clock hours, tasks); check before use.

**Use it:** background for any cloud-render explainer; shows burst-to-cloud and hybrid were the pattern from the start.
