MacDonald says Untold committed to buying no on-prem compute: the machine room has a few switches and a couch [52:17-52:49]. Because all data is already in AWS there is no hybrid sync, no licence split and no follow-the-sun push; hiring 20 artists means giving them logins [53:21]. Sam Reid (head of technology) says they decide storage and render capacity as needed and can scale storage when a big job lands [54:24]. The reference setup: monitors, keyboards, mice and tablets with a zero client on the back of each monitor over Direct Connect, all else in AWS [55:58]. The Thinkbox team built a test lab in London for them [54:56].

**Use it:** a clean-slate case for a cloud-only small studio, with the trade-off that workstation latency, not render capacity, becomes the daily risk.
