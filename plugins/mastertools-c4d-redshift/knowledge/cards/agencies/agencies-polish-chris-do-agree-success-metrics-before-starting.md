If you cannot prove a project's impact later, he says the project was started wrongly [22:00-24:04]. At the start ask how success will be measured, quantitative (visitors up by a set number, bounce rate down two percent) or qualitative made countable (an average survey score over the last 100 or 1,000 customers). Agree to revisit in a set time (his example: three months). Then assign a value to each metric ("what is that worth to you") before work starts so the value talk is easy later [23:33].
**Use it:** Add a "measure of done" field with a baseline and a revisit date to the brief for any broadcast package or look-dev job where results can be counted (views, ratings, social engagement).
