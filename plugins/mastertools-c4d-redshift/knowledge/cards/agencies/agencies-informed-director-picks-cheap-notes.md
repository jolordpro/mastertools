On a 2-spot commercial, Nederhorst and the director sat together and did the previs, so the director knew how long each change would take [38:35].
In reviews he would skip a 5-day change and ask for two 2-day changes, getting more from the same time [39:38].
Everyone at the review was a supervisor-level artist, so the room did not need basic comment sessions and went straight to tweak mode [38:35].
Spoken name is mangled in captions ("Kazinski"); likely Joseph Kosinski, not checked.

**Use it:** In dailies, attach a day-cost to each note and rank notes by change per day, so the director chooses with the cost visible.
