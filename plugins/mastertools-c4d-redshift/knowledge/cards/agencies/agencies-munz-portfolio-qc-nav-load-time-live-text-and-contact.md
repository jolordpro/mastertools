Checks he flagged across about 30 portfolios:
- Name visible (he cannot match a tab to a resume otherwise) and email/phone/socials in header or footer [06:20, 28:30]; one-line elevator pitch at the top [05:49].
- End each project with a "next project" link instead of making the viewer go back to the home page [12:08, 20:03].
- Load time: 8 to 10 seconds for a project is "way too long" [35:26]; optimise hero images and lazy-load [16:22, 59:43]; test embedded video, one never loaded [19:32].
- Type as live text, not a flattened image, for readability, accessibility and SEO [23:15, 24:52].
- Reel: self-host, give it a poster frame, put it above the about section, avoid a black YouTube embed as first impression [47:00]. Muted auto-play beats a click-to-play link [35:57].
- Broken project links, SSL missing, copyright year wrong, white-on-white hover states, plus icon that closes a menu [34:18, 47:32, 50:14, 54:26, 59:11].
- Very wide full-bleed layouts can feel aggressive on a 30-inch monitor [23:46].

**Use it:** Run this list on any portfolio, reel page or case-study site before sending it out.
