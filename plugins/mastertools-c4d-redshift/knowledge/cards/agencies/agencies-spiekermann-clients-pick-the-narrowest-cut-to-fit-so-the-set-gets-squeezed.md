He drew bitmaps for a wide, a narrow and a very narrow cut. The client took the very narrow one everywhere because it fits more easily, and the long street names got squeezed, so it is not as good as it could be [24:59-25:31].

**Use it:** If an option is cheaper to fit, clients will pick it everywhere; hand over only the options you accept and set rules for which to use where.
