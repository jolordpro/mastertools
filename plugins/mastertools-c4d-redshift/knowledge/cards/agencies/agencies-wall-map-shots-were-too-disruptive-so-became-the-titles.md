After the pilot, viewers were confused about location, so Elastic made five previs map shots to cut in at each location change. They worked for orientation but interrupted the show, and doing them for all ten episodes was not workable. The map idea moved into the opening, where it became four subtly different sequences listing the places each episode would visit. [§1-§2]

**Use it:** If an explainer device interrupts the story, move it to a place where it can run uninterrupted, and offer variants by episode.
