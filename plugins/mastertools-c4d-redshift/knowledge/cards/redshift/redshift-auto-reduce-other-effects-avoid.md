The Unified Sampling page, as summarised in the verticals research, steers users away from the "reduce samples of other effects" option.
The ledger lists this setting's default state and current guidance as an open hole (section 11), so this closes only the guidance half, from a summary.

**Use it:** do not recommend that option in advice; re-read the page before it becomes a ledger row.
Maxon check (2026-10-31): CORRECTION: Maxon's System Advanced page says this option is enabled by default and Maxon does not recommend disabling it. The summary this card came from had it backwards; keep it on. (https://help.maxon.net/r3d/cinema/en-us/Content/html/System+-+Advanced.html)
