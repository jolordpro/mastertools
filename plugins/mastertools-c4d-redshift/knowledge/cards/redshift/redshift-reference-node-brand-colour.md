A brand material outputs the absolute colour; plastic, metal and glass materials each use a Reference node pointing to it [46:00-47:04]. Changing the brand colour once (then refresh) updates all [47:36]. Reference can carry whole node trees (bump, displacement) too [1:00:16]; a viewer asks if it is new, he says it has existed a while [1:00:55].

**Use it:** Count brand-coloured materials; if more than one, suggest a reference.
Transcript support: Reference node reading a surface from a helper material also works for toon line noise, with refresh needed (https://www.youtube.com/watch?v=i3YczHKxtbo [23:22-25:58])
