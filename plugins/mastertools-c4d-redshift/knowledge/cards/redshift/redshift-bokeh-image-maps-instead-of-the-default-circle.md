Real lenses have vignetting, dust, chromatic aberration and odd iris shapes, so Greyscalegorilla made bokeh textures for Redshift and Octane [00:01]. Categories include basic shapes with chromatic aberration, fresnel versions for a filmic edge, and 'simulated' ones with dust and glass flaws that look the most realistic [06:15-07:49]. Side-by-side test: the mapped version feels photographic, the default white circle feels CG [05:13-05:44].

**Use it:** Camera preset: set a bokeh image when depth of field is prominent; pick a subtle simulated map by default.
