Plugging a second noise into displacement replaces the first [50:15]. The Displacement Blender merges up to four layers, with weight or Add mode and per-layer scale [50:48-51:20]. Bump Blender merges bump with normal maps; for bump plus bump a Color Layer add or multiply is enough [51:51].

**Use it:** Fix for layered displacement overriding earlier layers.
Transcript support: Bump Blender with base and layers, blend weight 0 to 1; makes scratches dents (https://www.youtube.com/watch?v=RpiCCLHjlWQ [1:51:12-1:53:18])
Transcript support: Bump Blender default blend weight 0 disables the layer, Additive needed. (https://www.youtube.com/watch?v=TonSU8Ljm5c [56:31-57:38])
