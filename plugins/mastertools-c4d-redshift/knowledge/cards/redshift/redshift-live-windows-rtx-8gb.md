Digital Production states Live's hardware as Windows with an NVIDIA RTX card of 8 GB or more. Mac support for Live was left unconfirmed in the research.
The ledger (section 3) says the Native engine uses MetalFX on Macs with Apple hardware, so Live does run on Mac. The two disagree; the article may only be quoting the Windows requirement.
