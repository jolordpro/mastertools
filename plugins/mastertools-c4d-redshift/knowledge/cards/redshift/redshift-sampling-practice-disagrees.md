CG Shortcuts: automatic sampling on almost always, it optimises better than hand overrides [08:21, RF; 01:04, RT].
Greyscalegorilla's Chad turns it off because it is too slow for him, uses a high threshold and low min as a starting point [57:24, GSG].
Daily Course turns it off and uses overrides; but then tests automatic sampling as an extra speed-up in its last scene [10:02, DC].

**Use it:** coach: present automatic sampling as the default and manual as an advanced alternative, and say that it is a choice, not a rule.
Transcript support: Polybox turns Automatic Sampling off (found slower, weak on volumes and extreme DOF); manual setup takes him 10-15 min (https://www.youtube.com/watch?v=Q5AZ7Xlh2I4 [24:05-25:39])
Transcript support: Gernge also turns automatic sampling off for threshold, min, max and overrides (https://www.youtube.com/watch?v=s5ElfI1q8uU [00:32-01:04])
