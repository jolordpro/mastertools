Deepblendart treats a rim light as a technical focus tool, not an emotional one: the same rim on a darker, harder-shadowed portrait reads intense, on a flatter one reads soft [01:16]. A rim on a dark edge turns a flat standard-lit image into one with a clear subject; a red/blue two-sided rim pulls the eye at once [01:47]. Placement: an area light behind the subject, scaled up, slightly off-centre for one-sided, colour per side for two-tone [02:19]. For a hero character he used two rim lights with light linking so only the character gets the edge, and kept the main light further back [03:21].

**Use it:** when a hero object reads weak at its edges, test the rim on/off pair; link the rim to the hero so it does not spill onto the set.
