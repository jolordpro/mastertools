His order: set ISO 100 and the 1/200 s sync speed, meter the key, and pick the f-stop you want by raising or lowering the flash power (for him f11) [04:28][04:58][05:30]. Then set the fill about one to 1.5 stops under the key by metering with the meter's memory and delta-EV function; his reading was -1.4 stops [07:03][07:34][08:36][09:09]. Metering both lights together read about f13, higher than the key's f11, because the light adds; so if the final exposure should be f11, start the key near f9 to f10 [09:40][10:10]. He meters with the dome down to read only light coming straight in [08:05].

**Use it:** same logic for CG: when adding a fill, the total exposure rises, so re-balance the key; use measured ratios (check lighting-ratio-measured-key-side-to-fill-side-doubling-per-stop).
