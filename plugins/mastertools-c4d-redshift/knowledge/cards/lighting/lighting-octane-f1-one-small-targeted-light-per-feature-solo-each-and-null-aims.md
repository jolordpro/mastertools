Nikita Kapustin (LearnPlasticity), F1 car [03:44-13:35]. Sky tag to 0 and an HDRI used only to set the camera; no environment light in the final [03:44]. Aim each light with a null so the light never needs rotating [04:15]. Start with a targeted area light named for its job (nose, cockpit, front wing, rear wing), lower the power, set camera highlight compression almost to the top so spots do not blow out, and set the light's opacity to 0 so it is not seen [04:47]. Distribution uses a falloff map at 90 degrees for a softbox feel [05:19]. Switch off every other light while working on one [06:50]. On complex geometry, never one big light: small sources give hot highlights and bright against dark places that show the design, while an over-lit object looks flat [07:51-08:53]. Exclude the ground from a light with Light Pass ID 3 on the light and the matching tick on the ground's object tag [09:55]. Name all lights [17:45]. He admits the pass took about 20 minutes of explanation, because the point is the thinking, not the positions [14:06].

**Use it:** Use for product or vehicle shots: list the features first, one job per light, solo-tune, then combine. Same discipline works with Redshift area lights.
