Like Welles, they used true theatrical fadeouts on old plate dimmers, so some parts of the frame go out first and something, say a foreground actor, lingers. He marked the moments in the script, then planned with the gaffer using diagrams based on how the director blocked each scene [§2]. Fadeouts introduced flashbacks and hard cuts or dissolves marked the return to the present [§2].

**Use it:** If a fade must be selective, do it on the lights, not in post, and plan which source goes last.
