Fraser says VFX supervisor Paul Lambert understands that if the lighting is not right for a scene, post cannot make it look great, so he pushed for accurate lighting. That meant the DP was not inventing lighting rules around things he could not see. Four to seven key minds were aligned behind the director's vision, which he says is not common. [§3]

**Use it:** CG lighting should copy the logic of a real plate's light so the two read as one; fix the match before polish.
