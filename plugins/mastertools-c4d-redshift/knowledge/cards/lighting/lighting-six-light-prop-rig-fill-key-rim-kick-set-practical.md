Leo in Color [00:30-05:34]. Fill: a dome light with a very soft HDRI as base brightness. Key: about 45 degrees to one side of the prop, exposure raised, temperature added; values tuned at the end. Rim: slightly behind on the opposite side, cooler than the key (moonlight through a window), exposure raised and spread narrowed for a crisp, directional edge. Kick: like a rim but emphasises shape; for a square subject, placed above so light falls over the top and defines the edges (readability). Set or back light: a point light enlarged almost to the size of the subject, strong, very warm, to shift the blue background around the subject and add colour contrast; fine in a portfolio piece, unrealistic in a grounded scene. Practical: a visible lamp, candle or screen that is both functional and part of the look. Review lights in Arnold's Light Manager with mute and solo.

**Use it:** Template for a hero-prop rig where each light has a stated job; matches the 'what is this light for' habit.
