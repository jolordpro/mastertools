Plugin by Greyscalegorilla and KitBash3D, released 2026-09-22.
Features per the video page: solo a light, batch edit colour, temperature, intensity, exposure, size and spread, look through a light to aim.

**Use it:** when the platform writes light levels, show a solo control next to each number.
Transcript support: Pros solo one light at a time to learn what each contributes. (https://www.youtube.com/watch?v=kN00Z7UsW5U [09:56])
