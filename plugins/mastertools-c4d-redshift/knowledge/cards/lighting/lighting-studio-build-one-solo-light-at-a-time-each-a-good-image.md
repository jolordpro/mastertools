RenderRam [00:00-10:23]. Throwing many lights in gives 50 unexplained highlights. Instead: (1) set the final background colour first (a white-product render made on grey fell apart on white in Photoshop) [01:03]. (2) Decide how many lights and each one's job: here right, front, and a rim, so three. (3) Solo each light, move it until it gives the highlights and shape you want as if it were the only light; check that detail such as a bumpy section is not swallowed. (4) Aim for three cool single-light images, which combine into a strong whole. (5) Fix problems with the lights you already have (shrink the rim highlight with a smaller local size) before adding a new one; the dark front got a fourth light at power 20 as fill. The point: no surprises, because you always know which light makes which highlight.

**Use it:** Matches the Light Manager solo idea: the coach can advise 'solo, tune, then combine' for any rig with unexplained highlights.
