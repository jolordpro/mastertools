He likes to be involved in scouting, set design and key stylistic choices so he doesn't discover on day one that a location blocks camera moves or a set needs another lighting setup [§2]. No camera is perfect; for 1917, supposed to read as one long take, the rig had to be light enough to run for hours over harsh terrain, with compact lenses and stabilisers that can be adjusted quickly [§3].

**Use it:** Resolve camera and set constraints before lighting detail; choose tools from the shot's physical demands.
