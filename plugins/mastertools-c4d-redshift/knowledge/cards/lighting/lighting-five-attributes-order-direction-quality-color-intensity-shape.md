Cinematographer Luc Ung's framework [00:35-01:40]: direction first because it sets mood and is slowest to change on set; then quality (softness), colour, intensity, and last cut and shape. Colour (gels) removes light, and direction and softness change exposure, so leave the meter until the first three are right [19:02]. He says he has used this order for nearly a decade because it avoids redoing work [26:05].
Treat cinematography as interpretation, not simulation: light directions can be physically wrong as long as the other characteristics look plausible [08:51-09:54].

**Use it:** the coach should walk look-dev in this order (place lights, set size/softness, set colour, then exposure, then flags); do not tweak intensity before the first three.
