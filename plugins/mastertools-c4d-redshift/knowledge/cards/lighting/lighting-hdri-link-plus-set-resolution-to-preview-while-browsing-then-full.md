Add a Redshift dome light, add the HDRI Link Plus tag, then drag the dome light's Dome Map parameter onto the tag; the tag turns from grey to white when connected [00:02-01:03].
Open the Plus library by double-clicking the tag, from the tag's Base tab, or from the menu [01:34-02:05].
Set the tag's Advanced resolution to Preview while clicking through maps so each loads fast, and switch back to Full for the real render [02:05-02:37, 04:11]. Preview can be made the default [02:37].
Turn off Enable Background on the dome if the map should light but not show [01:03, 03:41]. Deleting the tag keeps the last chosen map on the dome [04:11].

**Use it:** Look-dev routine for product shots: browse fast in Preview, lock the HDRI, then render at Full.
