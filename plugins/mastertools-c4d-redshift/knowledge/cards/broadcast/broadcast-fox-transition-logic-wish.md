Transition logic means a graphics system can go from one graphic to another on the same video input instead of cueing each on its own channel. He says it makes life easier for the technical director and uses less space on the switcher, but is far from solved. The dream: preprogram a complex series to roll in real time without presets for each [§2-§3]. From a 2009-era piece, so check against current systems.

**Use it:** When designing live packages, group elements that must follow each other so they can be sequenced on one channel.
