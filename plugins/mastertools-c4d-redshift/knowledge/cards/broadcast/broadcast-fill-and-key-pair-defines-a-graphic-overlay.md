In the mid-1990s a graphics system took scoreboard data and rendered a graphic as two video streams, a fill with the actual graphic and a key marking which pixels it affects, then a linear key unit overlaid it on the programme video [02:09-02:39]. Stadium scoreboards each had different ports and cables, so crews soldered and rewired to get data [01:37]. Networks first feared the score bug would drive viewers away, then adopted it everywhere (introduced 1994) [02:39].
The explainer is a VFX artist, not a broadcast engineer; details are second-hand.

**Use it:** delivery notes for live overlays: ask for fill+key (or an alpha) pairs, matching the standard live workflow.
