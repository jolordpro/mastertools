Overview [00:02-06:55]:
- Windows can be dragged into any dock; the Workspaces button resets to default or switches to a Viz 3.x layout [00:02-00:34]. Save a layout as a workspace.
- Main menu: import, archive (Viz's own save format for sending scenes and projects), post effects and post rendering, an on-air toggle for the on-air engine, config [01:06-01:37].
- Scene tree works like Photoshop layers, with plugins and geometries dragged into containers [02:09]; properties hold position, size, rotation, scale, lights and cameras [02:41].
- Assets live in the Asset View; the scene editor shows the scene and objects can be dragged live; keyframes sit in the separate Stage window found under available docks [05:19-06:55].

**Use it:** For onboarding a Viz team: set up one shared workspace and note that animation lives in Stage, not the properties pane.
