Thibault Baras (DreamWall, a subsidiary of Belgian broadcaster RTBF) describes the TF1 World Cup 2018 studio as the first hybrid he built [06:32-13:13]. It combined a real set with desk, chairs and audience, an LED wall, a virtual set extension, and a separate green box for storytelling. Three Reality render engines ran it: one for the LED wall, one for the extension, one for the green zone [12:06].
The hard part was a real arch in the set: the extension had to be masked around it and still line up with what the LED wall showed [17:32].
Baras gives three reasons clients ask for this: guests can see something on the LED wall instead of an empty green room, the extension merges the real set into a virtual stadium, and the green box does anything else [19:38-20:45]. He says the hybrid is now the standard request. TF1 staff were trained to run the weekly Telefoot show themselves.

**Use it:** Treat a hybrid studio brief as three or four separate render zones with an agreed masking edge, and count render engines per zone when sizing a real-time build.
