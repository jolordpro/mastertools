The player-card background is a Photoshop-style layer stack [36:20]. From the top: an overall grey that mutes and darkens [37:22], a grunge mat over a solid white for texture [37:54], a team-colour pattern used as a mask, and a gradient where a darker bottom colour hides the lighter one beneath [39:56]. A simple UV panner at speed 1 on X keeps the pattern drifting for as long as the graphic is live [39:25]. All of these values are exposed to the operator through remote control [40:28].

**Use it:** Copy the recipe for live-on-air backgrounds in C4D/AE: colour from a palette slot, pattern as a mask, tiny constant drift so the frame is never dead, grunge for texture.
