The old model: with 100 deliverables, hand about 30 to each vendor, and the vendor returns a package with, say, five end stamps; when the producer picks one, four never run and there are no assets to build anything else [01:38]. The new model: Man vs Machine and Big Block built "blocks" while the ESPN team made the deliverables [02:09]. The hard part was coaching the vendors to make pieces and not finished spots, and handling two groups that had to merge their work at a set point with a look at each other's stuff, which he called risky [02:09][02:39]. Whisper transcript of a trade talk (SVG), speaker's own account.

**Use it:** a plan for a big package: pay vendors for reusable building blocks, keep assembly in house, and decide early when parallel vendors see each other's work. Transfers to a Redshift/C4D library of scene-ready pieces.
