Transcript starts at 02:17. Notes [02:17-06:25]: the preset sets editing mode (DV PAL, DV NTSC, HD-SDI), time base (25 or 29.97), pixel aspect ratio, frame size and field mode; Custom unlocks each separately and is for non-broadcast displays such as LED boards that are not 16x9 [02:17-03:19]. For broadcast, stick with presets (he chose 1080i 29.97) [03:19].
Do not point a project at a drive root; browse to a projects folder and make a new folder for it [03:51-04:21]. The Create Project Structure checkbox (on by default) builds folders for images, audio, video, 3D models, fonts and miscellaneous (data, PDFs) [04:21-04:51]. A new project starts with Scene 1 in the Project Manager [05:21]. Because assets sit inside the folder, moving the folder moves the project to another system [05:53].

**Use it:** Use as a handover rule: one folder per XPression job, assets kept inside, so a project moves between machines whole.
