Pack made for the Celtics [12:27-13:29]. Because the designer worked directly with the team and knew the roster and assets, everything was embedded in the file. A control picks the decade (70s shown) and updates background and card; another swaps which player appears (Tatum, Grant), and a colour option adjusts quickly. The editor sets ins and outs and renders MP4.
His point: the work is front-loaded, so the editor's turnaround on each graphic shrinks.

**Use it:** Embedding a known roster trades file size for speed; use it when asset lists are fixed and team-approved.
