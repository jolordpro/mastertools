Countdown [13:43-16:31]: Display tab, Widgets, new Widget, clock timer properties; change mode from real time clock to timer, direction down, start at 59 seconds, format without milliseconds, size the text, set the text's data source to the timer, then Start and Reset from the widget column (used for a 60-second showdown).
Media [16:31-19:14]: the presenter says XPression does not accept most common formats, so an MP4 cannot just be dropped in. Close XPression, open XPression Video Coder, new job, add the file, render queue, wait, then reopen XPression, add a background, in the materials tab choose new file, and send it to the sequencer.

**Use it:** Bake media conversion into the show prep schedule; do it before the day, not at the truck.
