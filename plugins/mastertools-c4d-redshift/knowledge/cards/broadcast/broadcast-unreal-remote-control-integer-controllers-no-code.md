Remote Control exposes a property to one central panel by clicking the eye icon [28:34]. Handing an operator a free colour is risky, so a controller (an integer) with conditions gives only chosen options, no code or Blueprint casting [28:51-29:22]. Duplicate the controller and change the colour for a new theme [29:22-29:52].
Broadcasters struggled with Blueprints, which is why this was added; it arrived in 5.1 with six or seven behaviours, more promised [29:52-30:24].

**Use it:** Design operator controls as a small set of named options per element, not open parameters; fewer wrong picks on air.
