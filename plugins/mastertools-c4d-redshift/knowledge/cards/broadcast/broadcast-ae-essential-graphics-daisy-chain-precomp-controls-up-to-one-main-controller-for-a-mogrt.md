Baller FX (sports motion design): Essential Graphics is not only a MOGRT exporter; it can pass controls from a nested precomp up to the parent [02:37-06:20]. Method: inside the deepest comp, drag the controls (effects such as colour pickers) from the timeline into the panel, making sure the primary comp name at the top is the right one. The parent comp then shows an Essential Properties group; pick-whip its own controller to those properties. Repeat per artboard and finally in the main comp, so all colours run from one place [03:39-07:21].
Drops must come from the timeline, not the project panel [02:05]. Text is added with source text and can be dragged from any precomp [07:53-09:00]. After building, test every colour and every text field, including odd colours, then undo [10:01-11:51].
Example: a WNBA-style stats graphic with a player dropdown (name and face), three stat numbers and three colours.

**Use it:** Use this chain for any multi-comp sports graphic that has to hand over as one MOGRT.
