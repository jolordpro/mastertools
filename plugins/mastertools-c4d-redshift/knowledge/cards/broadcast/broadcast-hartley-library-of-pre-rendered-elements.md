Beyond live graphics, each Fox program carries about 50 unique pre-rendered elements (openings, closings, interstitials, bumpers, bugs) loaded to server, in SD and HD versions at the time of the piece.
The same look, set under Hartley, has to survive in all of them. [§2]

**Use it:** A broadcast look is a kit, not a frame. Test a hero frame against the smallest element in the kit (a bug) before calling it done.
