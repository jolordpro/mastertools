Alberelli [19:19-27:45]: a Create Playblast button renders the viewport, sets the task status (such as done), attaches a comment and thumbnail, and uploads to Kitsu. The same MP4 sits in a shared folder: editorial/footage/shots/<sequence>/<shot task>.
In the edit file, a playblast is loaded by hand the first time per task (animation, lighting and so on); after that an up-arrow loads the newest version. The edit then plays animation, lighting and later render in the same slot.

**Use it:** a review flow that always lands work back in the cut catches timing and continuity issues sooner than shot-by-shot review.
