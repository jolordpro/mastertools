Magnus Mela (Tumblehead co-founder) [22:01-27:34]: rig, then one-click publish of the rig for animators and a USD for shading. Because the team is small, all characters sit in one shading file so materials are reused and mismatches show when seen together (subsurface and colours that don't sit well). Shots are built one file per sequence, with prism import nodes making thumbnails and shot numbers, merging animation cache over shading assets. A sequence lighting setup is dropped into each shot and tweaked with light-mixer overrides. Artists need not know layers or sublayers. He also notes a ZBrush integration with the Prism browser removing file-path chores [27:34-29:46].

**Use it:** For multi-asset looks, view characters side by side before locking materials.
