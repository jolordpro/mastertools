Hugo Guerra keeps the editor's shot numbering on the project all the way, so 'shot three' means the same to producer, director and artist [19:08-19:38]. Boards and animatic share names too (board shot 1, ...), so in a meeting he can go back to the approved animatic when a client says the shot is not what they meant [22:53-23:49].
Animatics shared with the client include reference and inspiration plates to start a conversation about the look [23:49-24:20]. One project can reach many versions; that is normal [23:49].

**Use it:** Naming standard: one shot id from board through render, stored in the timeline.
Transcript support: Scratch conform renames clips to the VFX shot name but keeps the original source name in a Real ID column for traceback (https://www.youtube.com/watch?v=pWT2nk1vCt8 [06:56])
