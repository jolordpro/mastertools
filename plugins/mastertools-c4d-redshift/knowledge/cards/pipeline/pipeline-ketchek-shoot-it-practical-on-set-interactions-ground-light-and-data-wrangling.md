Michal Ketchek (VFX supervisor/producer, Magic Lab, Czech studio) in a CEE Animation webinar; auto-captions, so some figures may be misheard. Best VFX pairs practical elements with digital [04:01]. Build the set to first-floor height and extend digitally only for wides [42:19]. Keep interactions on set: build the ground actors, cars and horses move on, which beats simulating snow later [42:49]. Keep real light sources on set even if a stick-holder must be painted out [43:21]. Makeup effects on set with CG extensions where needed (a removed nose); blood is usually left to VFX because redressing after each take is slow [43:51, 44:22]. Virtual production gives real reflections and light interaction (First Man's LED reflections), but everything shown on the wall must be prepared in advance [44:52]. A VFX supervisor is on set; the data wrangler captures chrome and grey balls per shot, a colour chart per shot for a neutral grade, clean plates, measurements and 360 HDR maps [48:48, 49:31]. His view: the best VFX is the kind viewers do not recognise [34:25].
