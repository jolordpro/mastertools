Michal Ketchek (VFX supervisor/producer, Magic Lab, Czech studio) in a CEE Animation webinar; auto-captions, so some figures may be misheard. The VFX editor sits in the cutting room and keeps editorial and the VFX house in sync [50:06]. Shot names run project, scene, shot in steps of 10 so shot 25 can be inserted later without renumbering [51:06, 52:09]. Each shot has a description and handles (8, 10, 16 or 24 frames) beyond the edit, written down so the vendor renders longer than the cut [51:37]. Versions come back: first an animation version approved by the supervisor, then comp versions, each with feedback collected [52:43]. The edit keeps changing, so a shot can get much longer or shorter and that must be communicated with timecode tables [53:46]. Editorial works with postvis or temp comps, with bigger handles [54:18]. A tracker (ShotGrid) shows each shot's steps: tracking, matte paint, animation, lighting, comp, and who owns them [1:00:01]. Shots start at version 0 (what is in the edit), go temp comp, animation, final animation, creative final, then a QC pass for grain and edges [1:01:07].

**Use it:** step-of-10 naming and handles-in-the-ticket are cheap rules to copy for delivery packages.
