Guest George Razon (VFX supervisor, Soho VFX; credits include The Boys, Game of Thrones, Umbrella Academy). On a repeated effect (Homelander's laser eyes), different artists give each shot a slightly different look, so Soho QCs the whole set [34:33].
Reviews happen in the screening room so the supervisor can flip quickly between shots and load a keystone shot to compare against [35:03].
If still unsure, they lay out a contact sheet of every matching shot and pick out the odd one [35:34]; plates graded differently make this harder [35:34].
Artists get a reference to work to so every shot starts from the same look [34:33].
Transfers: a broadcast package with many near-identical lower-thirds or wipes should be judged as a contact sheet against one lead frame.

**Use it:** In a multi-shot review, build a contact sheet of all shots using the same effect and judge outliers against a keystone frame before judging any single shot.
