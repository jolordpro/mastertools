Jared Brashier [02:46-09:55]: the 3D drive stays on the Thunderbolt port of the home PC; a second drive with video/graphic elements travels. Local tree: libraries (C4D asset browser, Greyscalegorilla, Blender) / models / supplements / furniture / nature, down to texture files. Cloud (Google Drive, 8-10 clients): one folder per client with branding, current project files, final exports, schedule document; frequent assets duplicated there; project files can live there if assets are in the same synced tree so nothing de-links. He expects to move to a Synology server when he grows. Time claim: 35 s vs 5 min to find an asset adds up to days.

**Use it:** Keep libraries, models and project files in separate branches; keep assets inside the synced tree.
