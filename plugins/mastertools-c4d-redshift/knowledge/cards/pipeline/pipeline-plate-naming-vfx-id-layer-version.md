Plates are the layers of a shot; the main filmed layer is the hero or foreground plate, named like FG01, and backgrounds BG01 [08:23].
Name pattern shown: VFX ID, underscore, background or foreground plus layer number, underscore, version (for example TR10_FG01_v01) [24:44, 26:37].
If the shot is extended past its handles or slid, redeliver as the next version of the same plate [26:00].
If the take changes but it is still the same effects shot, it is a new layer number: FG02, version 01, not FG01 version 02 [26:37].
Colour completed plates in the timeline as you rename them so a long run is not repeated or skipped [25:30].

**Use it:** Use shot-ID_layer_version naming for render outputs and hand-offs; reserve version bumps for re-delivery of the same source and a new layer number for a new source.
