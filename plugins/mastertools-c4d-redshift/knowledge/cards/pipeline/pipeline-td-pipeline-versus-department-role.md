Speaker is the TD Academy host (surname garbled in captions). Pipeline TD = bridge between departments and the production, writing tools to start and finish a department; department TDs write rigging, animation or modeling tools [28:44-29:45]. He says advanced Python is a must, plus Linux shell, Git and several apps, and databases like ShotGrid or ftrack; he thinks there is no junior pipeline TD, because it needs years in a department plus communication and documentation skills [29:45-31:53]. Scale he draws: artist, technical artist, technical director, software developer [31:53-32:56].

**Use it:** Reference for what to ask when hiring or scoping pipeline help; opinion of one educator, low confidence.
