wip holds personal work in progress and must not go down the pipeline [§4]. versions holds everything submitted for review and also does not go down the pipeline [§4]. published holds the latest approved version copied in with the version number stripped from the file name, and is what other departments pick up [§4]. Each element has one publish file, which should reference an approved version [§7].

**Use it:** Name outputs by folder purpose so downstream artists only ever see the published copy.
