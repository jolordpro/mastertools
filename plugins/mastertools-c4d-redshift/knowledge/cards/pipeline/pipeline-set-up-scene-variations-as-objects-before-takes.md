If you add objects inside a take and return to the main take, the new objects will not be turned off, so he builds the variants (a second hero, a cloner ring) in the main scene, then creates the takes [18:33-19:03, 21:29]. He adds a camera and a wider render setting of 2560 by 440 for a cinematic strip [16:57] and duplicates the camera for close-ups [15:52].

**Use it:** a take hygiene check: after adding objects for a take, review the main take's visibility.
