Sacha (showrunner at Omens Studios; surname not captioned) started Python after 15 years of fearing it. His method: write the tools that you want; no classes needed; a chat model helped a lot as a tutor [12:19-15:24].
Goal: all basic, maintenance and complex tools in one place; he built three add-ons (general, character-specific, hair-specific) [11:48, 21:40].
Example: one button loads linked characters and overwrites libraries, a task that takes many menu steps by hand [12:22].

**Use it:** supports building small helper scripts for C4D/Redshift (scene starter, naming, render setup) driven by real repeated chores.
