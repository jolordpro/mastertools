In the Q&A, asked whether the studios went beyond v001 naming, the researchers said all three rely only on naming conventions [45:52] [46:23]. Games differ because they use version control such as git; with heavy scene files the simplest approach is a new iteration of the file [46:23].
They also said studios often reinvent the wheel because they lack blueprints from other productions [43:10].
