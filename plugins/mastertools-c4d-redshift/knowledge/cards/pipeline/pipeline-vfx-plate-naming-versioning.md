Richard Sanchez numbers plates from the start (bg01, bg02) because bg01 may drop out and bg02 take over [18:47-19:23]. Every number gets a version: bg01 v1 becomes v2 if the plate is re-pulled, say extended at the tail, though the plate itself is unchanged. Codes: fg/bg, lt/rt for split screen, gs green screen, bs blue screen, rf for reference (gray ball) [19:23-19:57]. He names the screen colour so the vendor sees the plate type at once.

**Use it:** same pattern for layer/pass/shot filenames in the render platform: role + two-digit index + version.
