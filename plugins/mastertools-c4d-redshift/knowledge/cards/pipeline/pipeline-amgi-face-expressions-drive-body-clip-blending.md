AMGI demoed a face tracked by a phone driving full-body animation by blending pre-animated, high-quality clips keyed to expressions such as happy, sad, worried, with eyebrows up triggering arms up [38:01, 39:36, 40:06]. Actors can also record their face in 3D from home, which is retargeted onto the character as a 60% head start for lip sync, expression and eye darts [41:08, 41:39, 42:10]. Brady speculates machine learning will extend this but says it has to start from a person's inspiration [40:38]. Unreleased tech shown as a teaser.

**Use it:** Low relevance: a pointer that remote face capture can feed a character rig when a job has a talent-recording step.
