Guest Hugo Guerra's company has no office. He usually has about five remote artists and had 20 on a full-CG trailer, using an entire remote pipeline so artists work as if at the Mill [08:25, 08:55]. Security measures he names: Dropbox Business with encryption, encryption tools on files, secure servers, and a server away from personal machines; he says it costs money and effort to build [1:10:02, 1:11:06]. He predicts hybrid shops and cites Jellyfish Pictures (about 300 in London plus satellites) [1:12:09]. Juniors should work in a big company at least once before going remote [1:11:38]. Hugo says he did game trailers for Ubisoft, Sony and Deep Silver this way.

**Use it:** Reference when the platform's cloud render and asset hand-off need client security wording: encrypted storage, servers off personal machines.
