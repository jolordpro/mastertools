Richard Sanchez: a count sheet lists shot number, frames in handle, frames in cut. That is the length the editor expects back [16:33]. A lineup (per shot) lists each element, e.g. bg1, bg2, with cut frame range against element frame range, so the vendor knows how the elements assemble [17:08-17:41]. He uses FFOC and LFOC (first/last frame of cut) for where a shot starts and ends [18:15-18:47]. The captions say "first stream", a mishearing.

**Use it:** a scene check that compares rendered frame count to the agreed count-sheet number (cut plus handles) catches short or long deliveries.
