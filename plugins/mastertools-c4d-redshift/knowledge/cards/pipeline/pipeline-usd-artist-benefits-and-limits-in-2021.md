Benefits he lists: other departments' output is accessible and comparable, a weird playblast can be opened in 3D from another angle, USD loads heavy data efficiently so 3D review is practical, work started in Maya can be finished in Houdini, and artists need not ask others to re-export or re-render [32:06] [32:29] [33:01]. Iteration is faster and more interactive [33:01]. He says that if artists dislike the pipeline it is not a good pipeline [33:31].
Limits shown: Substance Painter could not import USD, so the Alembic modeling layer was imported instead [07:46] [08:18]; Maya USD 0.9 could not animate USD objects [16:31]; rigging was Maya references [12:56]. Import as USD objects for heavy geometry, but as normal Maya objects when vertices are needed [13:28].

**Use it:** Check current plugin versions before relying on any limit; treat as 2021 snapshot.
