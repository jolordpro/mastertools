Per Richard Sanchez: when a shot is first turned over, the vendor sends back a v0 with no work done [11:05-12:16]. It carries the CDL and LUT the editor supplied, plus any speed change. The editor checks two things before labour-heavy steps like roto: does the colour match expectation, and is the frame range right, including handles. A correct colour pipeline makes the rest smooth; a wrong one gets "painful".

**Use it:** for any handoff (C4D render to AE, or us to a client or colourist), return one untouched frame/clip through the full chain first and compare it with the source before building on it. Transfers directly to broadcast delivery.
