Speaker is the TD Academy host (surname garbled in captions). Numbered top level [06:30-12:35]: pipeline (project scripts and plugins), sandbox (temp or secondary files on the network, so work isn't stranded on a laptop), planning (producer side), pre (client and director references), footage (reusable textures, shaders, template assets), assets, shots, renders (per shot, including playblasts), post (edit, grade, delivery). Assets can be organised asset-then-task or task-then-asset; most start with asset and put each department inside [09:25-09:56]. For a small independent project; large studios move parts to studio level.

**Use it:** Starting skeleton for a render project folder; add a sandbox so nothing important lives only on a local drive.
