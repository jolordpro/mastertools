Department separation is done in shot sub-sequences, set up so an artist is never blocked because someone has part of it checked out [22:44-23:15]. Animation layers: hero and interacting characters on one, background action on another, so one animator is not on 15 characters for the whole production [23:15-24:15]. FX layers by type: explosions, tracers and impacts, atmospherics, each given to the artist best at it [24:15-24:50]. The layers are combined in the main edit.

**Use it:** When many people touch one shot, divide by layer or type so no one is waiting on a locked file.
