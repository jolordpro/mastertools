Speaker is the TD Academy host (surname garbled in captions). The core is four layers and the scripts are the last, optional one [03:41-06:18]. Folder structure defines where files go; naming convention defines names inside and outside software; software pipeline defines who uses what and how data moves; scripts only automate those three. If the first three are solid, a project can run entirely by hand and scripts are added later for speed and fewer mistakes [33:29-34:31].

**Use it:** Use as the order for any small-studio pipeline plan; do not start by writing code.
