Layout was one blend file per scene, cut with camera markers and many cameras to place storyboards in 3D [16:13] [16:31]. It also shows what the library needs: trees, rocks, plants, icicles, so library work started early [17:02] [17:33].
Sets link library assets and start from ground planes and rough models built in layout [18:37]. Ground contact must be watched through the whole production because characters need their feet on the surface while the set changes [19:08]. There were six main set files; the riverbed set was used in about 80 percent of the film and the rest were one-offs [19:39].
When layout is done he marks each shot with colour strips in the edit; an add-on writes the shots to the studio's cloud database, and shot lengths come from sequencer frames [20:09] [20:41].

**Use it:** Add ground contact and set-version drift to the pipeline risk list for long-run character shots.
