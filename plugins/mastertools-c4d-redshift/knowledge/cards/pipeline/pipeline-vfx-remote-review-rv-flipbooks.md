Justin Mitchell [48:40-50:46]: Scanline reviewed with shared RV sessions as flipbook tool and wrote notes into the tracking tool (captions say "short grid", meaning ShotGrid). Before 2020 the supervisor in LA used a full-size theatre screen video link to teams in Vancouver and Montreal. Workstations sat in a server room reached over PC-over-IP, so working from home meant carrying a small box and monitors.

**Use it:** pattern for cloud render and remote review: keep heavy machines central, share frame-accurate review sessions, log notes next to the shot.
