Dave Schneider [06:44]: expensive shots were rendered, then re-rendered, because nobody knew which camera was meant. Clients had approved version six while the latest was nine; the instinct to grab the newest is wrong.
Clients also ask to go back to how it looked months ago, which sets off a scramble of timestamps to find the scene file [08:17].
Union's goal is a clear record in each shot of the approved assets [03:08] and backtracking from a dailies note (supervisor prefers model v3) to the source [03:39].

**Use it:** Add 'approved version' next to 'latest' in any shot tracker or render-submit check.
