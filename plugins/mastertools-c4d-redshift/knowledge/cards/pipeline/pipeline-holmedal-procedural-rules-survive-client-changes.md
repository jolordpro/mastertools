A sports-shoe job started as abstract structures; hundreds of versions in the dailies; then the client wanted five or six shoes, so the work moved to treating a shoe's surface and silhouette [01:47-03:21]. Because the systems were driven by simple geometry, any shape (torus, test object, old shoe) could feed them, so late changes did not force a restart [03:52-04:57]. The brief names are partly garbled in the captions. Houdini is the tool he credits for this reassurance.

**Use it:** Prefer systems driven by input geometry or parameters over one-off setups on a hero object so they survive client changes.
