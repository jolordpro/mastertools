Doing all layout, then all animation, broke his momentum. His fix: keep all shots in one file but jump around, lay out one shot and animate it right away, then another [19:36-20:07].
Planning replaces storyboard and animatic with rough thumbnails: shot count, screen direction, main action. Timing is fixed later with tools at any stage [20:07-21:08].
He wants multi-shot files so one render can run while he is away [11:17].

**Use it:** a lightweight planning sheet for solo projects: per-shot thumbnail, direction, action.
