He made a glass-refraction node in about 10 minutes by asking an LLM (he mentions Claude) after seeing refracted black-and-white type on Pinterest, and combined copies at different angles [42:26-44:32]. With agents he now makes a folder with all references of the target and says 'let's make a custom UI that generates this' [46:36]. LLMs know ComfyUI code because it is open [47:07]. You need a goal first, and he can refine with options like 'only every other slice refracted' [45:34-46:06].
Because it is open source, nobody updates his install behind his back; he can freeze it [44:32-45:03].

**Use it:** Give a coding agent a reference folder plus a one-line goal; pin the tool version for client work.
