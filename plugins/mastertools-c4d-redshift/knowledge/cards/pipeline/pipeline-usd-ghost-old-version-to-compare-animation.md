When two animation versions differ slightly, flipping between them is hard to read [25:26]. Select both versions to load them into the same scene, then right-click the old version's department and set a colour (dark red) plus alpha, leaving the new one green or normal [25:48] [26:18]. Orbit around it to compare from other angles and save a playblast to show the team exactly what changed [26:18].

**Use it:** Review aid: ghost the previous approved version over the new one when giving notes on timing or position changes.
