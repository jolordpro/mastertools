Giuseppe Improta (VFX teacher; whisper transcript, accent may blur words): on set the VFX supervisor collects 3D scans of the environment, 360 HDRI images for lighting and a colour chart for light balance [02:10-02:45]. On film, the coordinator hand-logs lens, pull focus and stock; digital cameras write white balance, lens and focus distance into metadata [03:16-04:20]. Film plates must be scanned first [04:20].
Downstream: matchmove matches the virtual camera and object movement but does not pass its work straight to lighting; layout packages it, sets global scale so elements are proportional, embeds the solved camera and translates elements for departments using different software, which makes layout critical [06:03-08:48]. Static elements can go to lighting early. Digital intermediate is the final grade after VFX, usually done externally with director and DOP [04:52-05:27].

**Use it:** A turnover checklist for a plate: scans, HDRI, chart, lens/focus metadata, scale and camera from layout.
