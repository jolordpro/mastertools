Patrick Wongbo starts new projects several times a day, so he saved a template with settings and plugins already enabled [1:25:45-1:27:19]. Plugins he searches for: media (ProRes playback, DNx encode, media IO framework), Movie Render Pipeline, editor scripting utilities and sequencer scripting (for utility widgets and automation) [1:28:21], and Text 3D, which is off by default [1:29:22]. Plugins ship with the engine; they are modular and just switched off.

**Use it:** Build one project template per studio pipeline so artists never hunt for plugins.
