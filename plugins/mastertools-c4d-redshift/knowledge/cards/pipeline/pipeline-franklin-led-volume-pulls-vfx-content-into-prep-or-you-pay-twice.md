The content has to be ready before shooting, so filmmakers must treat it as seriously as physical production, or they spend the money twice [1:02:01-1:02:31]. One TV show picked green screen instead because designs were not final [1:02:31-1:03:03].
On Interstellar they used front projection instead of an LED volume; the black hole and wormhole had to be ready before the shoot, so a planned six-month software build was done in three, uploaded overnight for the next morning [1:03:03-1:04:36].

**Use it:** For any live or real-time use of a render, lock the content earlier, because there is no post stage to fix it.
