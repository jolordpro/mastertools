The latest export is loaded in each animation file as a sequencer strip lined up with the shot's start and end, so the animator sees the previous and next shots [26:29]. Animators save viewport renders in order on the shared server; these are what the team critiques and writes notes on [27:01]. Lighting test renders go in frames and load into the edit [29:07].
The team published work in progress each Monday after Friday weeklies on the open cloud [06:29]; he mentions the openness invited a lot of advice [06:59].

**Use it:** Make context part of the shot file: always show neighbours from the latest cut. Keep a single folder of sequential review renders for notes.
