Winchester [39:11-40:49, 44:27-46:03]: you will not remember an annoying issue, so log it. Every project ends with a postmortem where everyone answers what went well and what went badly. Before coding, draw a Miro chart of boxes and lines, with notes on what each file should and should not do; he uses the pipeline himself as a VFX artist, to hit bugs first.

**Use it:** borrow the postmortem prompts (went well, went badly) for the wrap-up of each C4D job.
