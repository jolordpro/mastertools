Blender Studio director (2023). Rule set [00:02-05:48]: decide the previz method per project (agent 327 used mixed media, Sprite Fright a storyboard animatic, Charge a 3D semi-storyboard because of a tight deadline and no storyboard artist) [00:33]. Establish a screen-direction rule up front (hero travels screen-left to right, back right to left) [00:02]. Mannequin characters from low-poly shapes, minimal rig, props modelled inside the previz file as sketches [01:04-02:08]. Lock aspect ratio and sensor first because they drive cinematography; use a non-see-through passepartout so composition reads; limit colour to a few greys [02:08-02:40]. Each camera is bound to a timeline marker; block a key shot with constant keys, make an alt a frame later and flip between them for A/B [02:40-03:11]. Budget: maximum 10 frames per shot, 20 only when it earns it, so each frame is treated as a storyboard drawing [03:11]. Export stills to a sketch folder with incremental numbering so older versions stay [03:42]; retime in a video-edit file on the stills, cheaper than animated shots [04:13]. Cheap fog is a semi-transparent plane with an array for depth; camera moves only when needed, simple dolly moves are animated in the edit [04:31-05:11]. Layout then rebuilds every shot from scratch in its own file, using previz as guide [05:49].

**Use it:** Pitch/animatic method for a sports open: cap frames per beat, keep A/B alts one frame apart, fix screen direction (home left to right) before blocking.
