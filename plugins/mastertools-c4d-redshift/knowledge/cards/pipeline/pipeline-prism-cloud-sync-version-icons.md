Dropbox shared folders worked for tiny teams but do not scale [19:24-19:56]. A managed cloud service adds a cloud database and storage; scene versions show blue for in cloud and green for local; artists download or upload per version, and automatic rules were still undecided. Early stage, one studio already using it [19:56-21:30]. Q&A: tracking render cost from Deadline was not on the roadmap [45:41-46:44].

**Use it:** Lean on per-version sync status, not whole-folder sync, when advising remote teams.
