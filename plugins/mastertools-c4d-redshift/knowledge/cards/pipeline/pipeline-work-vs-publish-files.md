Speaker is the TD Academy host (surname garbled in captions). Work = what you are editing; publish = what you hand to someone else [09:56-10:28]. A published model is what rigging references, so it updates downstream. Publish names carry only shot or asset and task and are kept as small as possible; the file is replaced in place and references always find the newest, so no version number in the name (version can go in metadata) [15:41-16:12]. Work files hold more detail, including how render files and AOV folders are named [16:12].

**Use it:** Use for handoffs from C4D to AE: a stable published render path plus versioned work files.
