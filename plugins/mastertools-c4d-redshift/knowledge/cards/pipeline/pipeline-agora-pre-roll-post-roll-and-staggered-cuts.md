Shots were staggered visually in the sequencer so the edit flow is easy to see and one cut's timing can move without moving everything on one line [20:09]. One extra frame can matter on action set pieces [20:39]. Animators therefore animate extra frames before and after (also useful for simulation) so edit tweaks stay possible late in production [20:39-21:09].

**Use it:** Add handles in animation delivery spec: pre-roll and post-roll frames beyond the cut.
