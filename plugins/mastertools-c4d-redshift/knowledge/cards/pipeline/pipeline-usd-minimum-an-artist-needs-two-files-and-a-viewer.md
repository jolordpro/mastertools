Booth [19:33-21:41]: component builder makes a best-practice USD component; the artist's job is to save the model into one file and the materials into another. They model in Max and texture in Substance, with USD View open to watch the asset update; layout artists see the latest after version control syncs, with no re-import. To learn: open Pixar's kitchen scene in USD View and look inside [15:51-17:29]. Install USD View via Nvidia Omniverse, not GitHub [04:52].

**Use it:** onboarding artists to USD: give them the two-file rule, not the whole spec.
