Because rebuilds are sums, multiply every pass (not just the final sum) by the map; the result is the same and each light shows the edits [47:45-50:18]. Only the first rebuild's changes appear in the second; changing the second does not flow back (that would loop). His rule of thumb: put the more drastic edits second [51:19-51:50].

**Use it:** template design choice: pick which rebuild is first.
