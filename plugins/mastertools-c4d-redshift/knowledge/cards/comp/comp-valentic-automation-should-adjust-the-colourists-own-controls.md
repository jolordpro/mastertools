His patented point: the algorithm matches by setting the same controls a colorist uses, so if it is not fully right, the colourist keeps going from where it stopped [12:14-12:45].
Speeds: about 1.5 seconds per shot on a very fast machine, 8-9 seconds on his laptop, and under an hour for an hour-long sequence once the looks and keyframes are set [12:45-13:17].
He compares it to a car with autopilot but a steering wheel: automation needs a way back to manual control [13:47-14:17].

**Use it:** Prefer automation that outputs editable, named parameters over opaque results.
