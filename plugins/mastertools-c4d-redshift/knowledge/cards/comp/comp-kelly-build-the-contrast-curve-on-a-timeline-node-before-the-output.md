A look is the consistent visual signature across all shots [00:00]. Start with a timeline-level node (not clip level) placed just upstream of the final output transform to Rec.709, with the footage only technically mapped from camera space first [01:01-02:34].
Knee: pull a control point near the low end down for density; shoulder: push a high control point hotter; flip the node on and off across shots, or a set of hero shots, to see it works for the majority [02:34-03:37].
He then reopens the knee for one shot after viewing it, since the curve is set first and refined later [06:44-07:14]. Contrast should be the first step because it affects everything afterward [07:46].

**Use it:** Build the show look on an adjustment layer or timeline node above all shots, then judge against a contact sheet.
