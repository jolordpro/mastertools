They worked to get the dailies pipeline and on-set monitoring close to the final grade [1:01:51]. With the palette already set by production design, light colour and costume, there was no on-set grade [1:02:22]. They used on-set LUTs, exposed with a light meter, and the density stayed about the same through dailies and grade [1:02:22-1:02:54]. Testing is what makes this work.

**Use it:** Define the display transform and a reference exposure early so every review image looks like the final.
