Kelly [1:23:16-1:26:54] invests in himself before equipment, since gear depreciates and only pays off if it changes the images clients get. His three musts: a machine that runs the grading app without constant limits; a dedicated output card so code values reach the display unaltered (a normal laptop or workstation HDMI port runs processing meant for GUIs, so it cannot do this); and a reference display that has been measured and shown to meet the standard it claims, not one with a "99% coverage" claim.
Without that trusted image he says a colorist cannot charge full value for the time.

**Use it:** the checklist for any "is this monitor fit for sign-off" question in the coach: unaltered signal path plus measured display.
