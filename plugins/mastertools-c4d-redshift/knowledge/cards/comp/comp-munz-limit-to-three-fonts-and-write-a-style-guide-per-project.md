Reviewing a poster set with a different font on each: he usually aims for three fonts for a piece like that and says to build a style guide and use it on every poster and social post [32:12-32:44]. Another portfolio with four or five typefaces on one piece: limit to three type treatments [1:06:02].
Consistency of small details counts too: colons, spacing and capitalisation should follow one rule across titles and body [53:23]. Large body text in all caps, bold and centred is hard to read; use sentence case and align left [31:08, 27:28].
Two fonts competing (cursive and sans) should be picked and aligned so they work in tandem [34:52].

**Use it:** Type check on any frame set or lower-third family: count the typefaces, write the rule, and compare every deliverable to it.
