His test set-up: a wide-gamut log working space, output Rec.709 gamma 2.4, some elements maxed out because subtle effects are otherwise invisible, a clean Rec.709 reference for each comparison, and waveforms, vectorscopes and CIE and tone-map graphs alongside [53:16-54:18]. The working space name is garbled in the captions. He first applied only the stock profile and saw the same warm, red-led behaviour as in the films [55:23-56:27]; a two-actor frame showed it forming a container for skin tones [1:00:11-1:00:42].

**Use it:** Build an A/B sheet with the look at exaggerated strength next to a clean reference, plus scopes, before dialling it back.
