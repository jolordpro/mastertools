Order on screen: negative palette first (colour character, not contrast), choosing by looking at skin rather than the stock name [16:04-17:45]; then contrast curves (film-print style S-curve; he liked one that put a bit of gloss on the lead's face) [17:45-19:23]; then print profile with film print emulation on, because it cleans up colour bloom [19:23-20:30]; then a global amount slider to A/B the look [20:30].
Principle: the show look should make skin beautiful from the start, with no need to open secondaries to fix it [16:38-17:13].
Both stocks are real Kodak print stocks: he turns down a 2393 contrast curve as too strong [18:18] and prints with 2383 [19:56].
Supports the earlier Valentic chain-order card.

**Use it:** When building a look, judge each stage on skin first and keep contrast, colour and print as separate steps so each can be backed off alone.
