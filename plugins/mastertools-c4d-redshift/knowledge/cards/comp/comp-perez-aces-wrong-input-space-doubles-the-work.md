His failure story: footage is ingested, the compositor sweats through the comp, then the lab says the colour space was wrong and the shot starts again, 'you die twice' [06:21-06:53].
The point of ACES is one agreed code so every department sees the same colour. It still shows only the best match each display can manage, not an identical picture [07:24-07:55].

**Use it:** Put 'what space is this footage / render in?' at the top of the ingest checklist before any comp time is booked.
