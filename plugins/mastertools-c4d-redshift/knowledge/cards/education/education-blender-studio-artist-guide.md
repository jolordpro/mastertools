Lighting guide: start only after blocking exists; four light types (key, key-soft, fill, rim) with one RGB value per type in a linked library file; light key shots first. Animation guide: shot delivery list (frame rate, latest version, assets linked, motion-blur suitability).

**Use it:** copy the four-role light kit and ask what a shot has before advising look.
