Nick Campbell says the tutorials he disliked just said type this number or use this exact hex value, which teaches nothing, like a piano teacher naming keys [44:37-45:37].
GSG focuses on why a decision was made (colour, camera, design) and not only how [45:37-46:08].
Five tests for a tutorial artist: has really done the work, can teach it, explains why, performs with energy as if to an audience, and remembers what it was like to be new [46:08-48:13].
