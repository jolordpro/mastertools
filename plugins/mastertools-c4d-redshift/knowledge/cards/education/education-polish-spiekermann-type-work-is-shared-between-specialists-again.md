Spiekermann says there are fantastic tools but it is very hard to master them all, so work is shared again: some people sketch, some program, some use production tools, as before desktop computers [§3]. He adds that type mirrors the visual world as quickly as music, since one typeface can take days alone but larger systems take weeks or months [§3].

**Use it:** Encourage users to name their strongest role in a pipeline and partner for the rest.
