Character art director's rules [11:00-12:34]: bold shapes (influenced by scientific illustration, block prints, folk art) with rich texture inside; no sharp corners or straight lines; no sculpted indentations (clavicles, knees) that would cause harsh shadows; deliberate irregularity (offset trouser cuffs, mouths that do not pinch symmetrically). The animators were told the history of each choice and it carried into bold poses and timing contrast between busy and quiet [13:05]. Each character was designed twice (sea monster and human) to feel like the same character, not match features [14:07-14:38]. Features are a few millimetres from a different character [14:38].
**Use it:** Write shape rules like these into a CG character or mascot brief so lighting and animation inherit them.
