Blender developers showed an OpenPBR implementation at Blender Conference 2026; still work in progress and expected for Blender 5.4, with EEVEE limits on dispersion and thin film [04:20-04:52].
OpenPBR is already the default material in 3ds Max 2026, is implemented across Substance 3D, and Chaos Vantage 3.4 added it [04:52-05:26].
The presenter cautions materials will not look identical everywhere; lighting, colour management and render settings still matter [05:26].
Same video: C4D 2026.4 (13 Sept 2026) ships an MCP server that is off by default, can limit tool groups, can disable Python, and logs actions in undo and a local audit log [01:39-02:46] (covered by existing MCP cards).
