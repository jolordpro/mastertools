Toy Story 5 (SIGGRAPH 2026 talk): the art director's colour keys and style frames were the north star for every department; comp got knobs for how abstract each area reads.
Raya (2021): the colour script drove lighting choices (search summary). No public numeric rule for colour scripts exists.

**Use it:** store palette and value plan from the approved frame; score each draft for drift in hue, value and contrast.
