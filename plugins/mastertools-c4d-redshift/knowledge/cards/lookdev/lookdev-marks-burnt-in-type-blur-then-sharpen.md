On his Semi-Permanent 2015 titles Marks chose a simple, classic typeface so it would not compete with the detailed imagery.
He softened the type edges with a slight blur, then sharpened, so the lettering reads as printed into the picture rather than laid on top.

Page spots: the type is Din Mittel, a classic face based on 1931 DIN 1451 [§6]; ornate type felt like too much against detailed imagery [§6]; minimal blur then sharpen makes type feel burnt into the image rather than 'super digital' from After Effects, a habit from analogue film titles [§6].

**Use it:** Test type with the same optical softness and grain as the plate. Keep the face plain when the image is busy.
