Doug Walker (Autodesk): the classic ACES config (HP Duiker, updated for ACES 1.1 and 1.2 by Thomas Mansencal) hit edge cases from 3D LUT limits; v2 built-in transforms implement the ACES algorithms directly, so the config can be LUT-free [14:08-15:43]. A new ASWF config project goes in two phases: first a reference config of only ACES transforms (target: ACES logo programme), then a studio superset; the config structure is generated by walking the ACES repository so CI can catch drift [08:21-10:26].
Also: Academy Common LUT Format (CLF) has full read and write support, and CTF is a CLF extension that serialises every OCIO feature [15:12-16:14, 52:21-53:25].

**Use it:** When a colour pipeline relies on ACES via 3D LUTs, note the clip risk in extreme highlights; the v2 config avoids it.
