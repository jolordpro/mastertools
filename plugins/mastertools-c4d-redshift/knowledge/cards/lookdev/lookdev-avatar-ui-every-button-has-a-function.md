Ben Procter says every button and display in the Avatar UIs has a name and a function and is organised around a realistically imagined model of user interaction. He avoided the usual film UI where a computer is barely touched and a long visual routine opens a folder [§4]. For the Link Room he aimed for one integrated electronic system with the same slick look and nothing floating, like a big medical device from one firm [§4]. The bio-lab design started from a trip to AmGen to photograph real lab equipment [§4].

**Use it:** For screen graphics, give every element a job; if it cannot be named, cut it.
