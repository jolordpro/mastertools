Normally this is a Preferences switch under Redshift renderer settings. Search 'node materials for presets' in Customize Palette and drag it to the toolbar [16:51-17:23].
With it on, Create New Material uses the node graph editor; off, the old shader graph. Reason given: Bridge creates normal materials and doesn't work well with node materials [17:23-17:54].

**Use it:** Flip the button off before importing Bridge assets, on for hand-built node materials.
