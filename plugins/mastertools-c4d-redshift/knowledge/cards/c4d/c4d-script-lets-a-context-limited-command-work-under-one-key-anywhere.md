Scroll to First Active is limited to the Object Manager, and hotkeys change meaning by panel; a one-line script containing it runs from anywhere, and he bound it to S [11:09-13:17].
Layout switching has no native command (only save), so he used a short snippet found on a plugin forum thread and edited the layout name inside it [13:17-15:59].
His V popup menu holds three layouts (UV, Redshift, default) plus a create-Redshift-camera script [15:59-16:31].

**Use it:** Per-project layouts as a button: Redshift, UV and default workspaces one key apart.
