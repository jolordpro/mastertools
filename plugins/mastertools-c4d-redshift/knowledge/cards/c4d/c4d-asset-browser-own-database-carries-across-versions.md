In Preferences > Asset Browser add a database folder (his lives on a home NAS) and save textures, HDRIs and gobos into it, not into the main shipped database; when R26 or the next version installs he only re-adds the path and everything shows up [13:26-15:54].
He can filter the browser to show his database only, and dragging a material onto the Materials section stores it [16:25-17:31]. He says the browser is much better than the old library.

**Use it:** pipeline: a shared database path is a cheap way to keep a studio texture and HDRI set the same across machines and versions.
