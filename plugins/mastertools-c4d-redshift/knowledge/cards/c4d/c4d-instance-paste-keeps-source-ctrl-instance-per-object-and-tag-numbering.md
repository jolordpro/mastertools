Copy-pasting an instance into another scene now brings the reference object with it, so it no longer arrives empty [35:29-36:00].
With three objects selected, creating an instance while holding Ctrl makes one instance per object rather than one for the group [36:00-36:30].
A second vertex-map tag (or any repeat tag) now numbers itself instead of sharing the name [36:30-36:55].

**Use it:** scene check: duplicate tag names are less of a risk from 2026.1 on; the coach mentions Ctrl-instance when many objects need instances.
