[02:07-03:23]: select the objects, right-click Show Tracks to isolate their tracks, then Bookmarks > Add Bookmark; rename in Manage Bookmarks (double-click); return with the Default bookmark; recall from the dropdown. Middle-click an object to select its children first.

**Use it:** A cleanup step before animation polish on dense rigs.
