Noseman, 2026.3 [25:50-31:09]. Brush modes include Relax for local relaxing, with the usual brush gestures: middle-click drag for size and intensity [26:22]. Straighten works in edge mode [26:53]. Align UV Island needs no selection: hover an island, then pick the edge to align to [26:53-27:26].
Texture display: empty canvas, checker, coloured grid, or any bitmap in the object's materials (here a Redshift material with three textures) recognised automatically; set the viewport opacity below 100% in Configure or filled polygons hide the texture [27:26-28:34]. Reference images can be loaded for tracing. A small paint menu with outline and fill polygon layers and an image Layer Manager (not the object layer manager) exports a UV guide to a 2D app [29:05-30:38]. Check each tool for a UV-specific attribute set (soft selection works with translate, scale, rotate) [30:38].

**Use it:** Use the colored-grid and texture overlays to confirm distortion before shipping UVs to a texture artist.
