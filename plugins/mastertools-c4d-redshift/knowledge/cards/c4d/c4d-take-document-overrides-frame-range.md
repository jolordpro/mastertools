Right-click in Takes Manager to override time min/max and preview min/max for the take [29:13-29:43]. Render settings can use Preview Range or All Frames and the save name can use the take name, so one render preset serves every shot [30:14-30:47]. The timeline also shows keyframes from other takes now [31:18].

**Use it:** scene check: per-take frame ranges feed the estimator; also confirm the take name is in the output path.
Transcript support: Timeline shows keyframes of other takes in the same hierarchy; auto overwrite edits them; example ranges pen 0-60 preview, doc 0-150. (https://www.youtube.com/watch?v=Xh8A767yA1U [28:40-32:02])
