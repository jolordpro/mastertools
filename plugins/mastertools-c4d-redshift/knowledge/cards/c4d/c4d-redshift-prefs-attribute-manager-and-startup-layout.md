Chad: in Redshift preferences, the Global Attribute Manager for shader nodes option shows a selected material in the main attribute panel, as in the old Xpresso nodes, instead of a separate panel [01:03, 06:46-07:17].
He builds a Redshift layout (viewports, render view, object manager, attribute panel, node editor) and saves it with Customization, Save Layout As, optionally as the startup layout so C4D always opens in it [05:14-07:17].

**Use it:** Setup checklist: after installing, set the attribute manager option and save a startup layout once.
