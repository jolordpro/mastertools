[58:21] Two new display modes beside material colour: Random (every object a different colour) and Object colour (the display colour, which is what feeds user colour data in a material).
Useful to tell apart objects in dense scenes and to see scatter colour variation without rendering.

**Use it:** use as a quick way to see object boundaries and clone variation in a draft.
