Right-click an object or use Create to open the dialog: source object and UV tag, target and UV tag, output folder [57:51-58:54].
Choose local or world sampling space (local when the pivots match) and optionally re-do the UVs; it writes new textures and a duplicate material wired to them [58:54-1:00:02].

**Use it:** a retopologised asset can be re-textured in one step rather than re-baked by hand.
