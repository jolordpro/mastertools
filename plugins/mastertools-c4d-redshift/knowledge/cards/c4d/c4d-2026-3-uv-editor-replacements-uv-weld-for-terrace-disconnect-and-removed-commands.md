Gone: interactive mapping, UV Terrace and Unstitch UV [12:45]. UV Weld tool: hover to see arrows showing where an island will land; click puts it back in place, and with edge-loop expansion and island transform turned off it welds just the selected edge; Control meets halfway, taking the average position [13:48-15:51]. Reset UVs and Store UVs are rare, so they are only in the Commander (Shift-C) unless the user makes a palette; Reset UVs in polygon mode collapses everything to the 0,0 point rather than deleting [16:22-17:58].
