Jonas (Maxon): a Europe map with country names placed on each country is called a great use for MCP automation, because making the hierarchy and text objects for every country is tedious by hand [14:04-14:36].
On the new Nodes Field and Nodes Effector (a sonar field, a reaction-diffusion example) he says MCP can help but is tricky: learn what the tools do first, then build more advanced set-ups [11:13-12:17].

**Use it:** Motion graphics: map and data-label scenes (team crests, stats, country tags) are a fit for scripted or MCP-driven build; keep a human check on the first one.
