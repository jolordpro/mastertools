Tags, selections, keys, objects and materials all add up [1:04:28]. A studio asset with about 100 material tags took six minutes to open; reduced to four tags and four materials it opened fast (time not given) [1:04:58]. Also: use procedural noise over huge textures; remove unused materials and objects.

**Use it:** Scene card should report tag and material counts per asset and flag outliers.
