New primitives appear at world zero even when working elsewhere in a big scene. Highlight the object, press Transfer, click the destination, and it lands there matching the axis [20:31-21:33]. The speaker only learned of it late.
Placement tools stack objects so they rest on others without intersecting, and can be combined with dynamics for settled placement [22:03-23:05].

**Use it:** Faster set dressing for stadium or studio scenes built from many primitives.
