With it on, typing 28, 231, 131 gives a pale, bluish green [00:36-01:07]. The same swatch reads 93, 244, 190 once it is switched off, so a transform is applied [01:38]. With it off, re-pick the colour and the RGB and hex match the brand guide [02:11]. Default off: Preferences > Units, then restart [02:43]. Single-creator tip; behaviour under ACES/OCIO not tested.

**Use it:** Brand-colour check: read the swatch value and report the picker setting; still measure after the view transform.
