With the camera selected, set influence from the previous or next key (he used about 37% of the previous) to create a new key at the current time [40:40-41:13]. Used to pull a camera back onto the subject mid-move without recording new keys.

**Use it:** Mention it when a move drifts off the subject between two good keys.
