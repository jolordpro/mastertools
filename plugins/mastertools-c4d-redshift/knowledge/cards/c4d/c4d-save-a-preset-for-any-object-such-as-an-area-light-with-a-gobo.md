[05:59-07:40]: set up the object (gobo texture, spread and so on), use the preset dropdown at the top right of the Attribute Manager > Save Preset; later create a new area light and load it from the same dropdown. Works on primitives, deformers and other objects. Heart icon in the Asset Browser adds favourites (Smart Search > Favorites) and in the Redshift node commander.

**Use it:** Capture recurring light setups as presets.
