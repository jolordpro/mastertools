Layout: dock the Redshift menu, render view, attributes and layers beside objects; add icons through Customize Palettes (zero-all script, connect, random, vertex weight, Redshift materials, AOV manager); then save as the startup layout [00:35-04:44].
Default scene: three nulls with coloured icons named Lights, Objects, Scene; cameras kept outside; a Redshift dome light preloaded with an HDRI Link; wall and floor; then Window, Customization, Save as Default Scene [14:09-16:51].
The same menu saves the default folder structure for new projects [14:09].

**Use it:** Starter template for sports-package projects: lights, camera and floor in place before the first cube.
