Jared Brashier [10:04-17:49]: Window > Asset Browser; Edit > Preferences > Asset Browser > Add Folder to create a database (his example is a 'centralized frequent assets' folder in Google Drive); right-click to make a category; connect objects, delete the original and drag the object into the category. C4D writes asset files into the folder, keeps the Redshift materials and textures, and the object drops into a new project already textured. Because the folder is synced, a laptop sees the same library.

**Use it:** A shared database folder on the team drive gives a studio library without extra tools. Test that textures resolve on the second machine.
