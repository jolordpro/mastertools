ComfyUI gives parameter-level control (for example motion blur amount as a number like 3.5 vs 3.7), which prompt-only tools cannot [57:30-58:31]. He says it is a UI for Python scripts, so anything Python can make can be a node [58:31-1:00:05]. When he first used Claude computer use to rebuild an After Effects animatic with about 150 layers, it wrote and handed a script to After Effects instead of moving things around [59:04-59:35]. He prefers hard-to-control tools for pieces he will post, and stopped Midjourney when it got too easy [55:26-56:59].

**Use it:** For bulk edits in AE/C4D have the agent write a script rather than drive the UI; keep manual controls where the look matters.
