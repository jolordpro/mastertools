Jason Schleifer (chief creative officer, Griptape, now Foundry). He recorded himself giving notes on an animation shot, ran it through a video-analysis API (Twelve Labs) to list notes with timecodes and departments [21:12-22:46], then an agent with a producer rule set summarised for the animator and answered follow-ups such as which notes affect layout (camera shake), CFX (foot arc means a clothing resim), effects (dust burst at foot contact) and lighting/comp [22:46-23:46]. A second agent turned the notes into timecodes for a split-video node to cut clips for the artist [24:17-24:47]. Workflows can run headless from a command and a watch folder triggers them [26:19-27:54]. Demo, not production evidence. Related: ai-models-aswf-dailies-notes-assistant.

**Use it:** Idea for a review-notes helper: department routing, timecodes, split clips; keep a person in the loop.
