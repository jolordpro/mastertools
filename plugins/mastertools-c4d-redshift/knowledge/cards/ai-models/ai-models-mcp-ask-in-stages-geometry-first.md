Chad Ashley built a wood scaffold scene in this order [46:22-49:25]: (1) sketch plus a reference photo, "build the geo" only, withholding colours and ropes; about 10 minutes. (2) add paracord, using the paracord materials already in the project; 5-10 minutes. (3) "show me three options, each on a layer". (4) materials: Redshift tags, object IDs and a shader switch that randomly paints some slats from a palette screenshot, only a few in the accent colour. (5) composition notes by drawing on a screenshot of the render.
Small fixes went in plain text (move the support struts from the front to the back) [51:26]. Late asks (countersunk screw holes only where the structure needs support, plus screw models) would have taken days by hand [51:58].
He placed the camera and lights himself and touched no other object except one prop he imported [50:56].

**Use it:** the coach can suggest breaking a big agent task into checkable stages, each saved on its own layer or take, so a wrong turn costs one stage.
