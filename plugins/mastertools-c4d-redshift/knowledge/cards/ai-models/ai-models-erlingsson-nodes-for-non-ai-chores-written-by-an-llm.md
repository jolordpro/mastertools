He says Comfy can do non-AI work and is a good interface for it. LLMs are very good at Python, so he makes nodes that solve problems that took a long time in After Effects, and they run in seconds [11:46-12:53].
He can read Python but not write it unaided; an LLM helps [13:56]. The same functions move into a web app with no Comfy back end, and could be translated to an OpenFX plugin for Resolve [14:27-15:29].

**Use it:** Script repeated chores (like the node-based glitch pass) once, as a small utility, rather than repeating the manual compositing steps.
