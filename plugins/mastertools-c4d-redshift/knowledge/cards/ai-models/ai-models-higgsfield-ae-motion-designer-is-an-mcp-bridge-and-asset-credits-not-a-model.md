A working After Effects user (single creator, critical of the vendor) tested it. The product gives no model of its own: you install an AE extension and an MCP server, and bring ChatGPT or Claude; Higgsfield credits are spent only when image/video/sound assets are generated [00:31-02:04]. Setup took nearly an hour; the first prompt produced a Higgsfield video, not an AE build, until the chat model diagnosed and fixed errors in the vendor MCP server [02:35-03:05]. Test 1, animate a logo shape layer in a 1080p 30 fps comp with no assets: trim paths and blinking eyes, "not half bad", no credits used [03:05-04:38]. He says the same is possible with a self-built AE MCP bridge, and the vendor's prompt tooling takes creative control away [04:07]. Marketing video is called false advertising by him (opinion).

**Use it:** Treat the vendor demo as AI footage, not capability. Judge any AE-agent tool by the comp it leaves behind and which part came from the base LLM.
